This page lists every keyboard shortcut in cfo.ai, grouped by where you use it. On Windows and Linux, use **Ctrl** where this page shows **⌘**, and **Alt** where it shows **⌥**. With the sidebar open, press **⌘ ?** to see the common shortcuts in the Help center.

## Search, help, and the sidebar

| Shortcut | What it does |
| --- | --- |
| **⌘ K** | Open or close workspace search |
| **↑** / **↓** in search | Move through the results |
| **Enter** in search | Open the highlighted result |
| **⌘ Enter** in search, or **⌘**-click a result | Open the result in a new browser tab |
| **Esc** in search | Close search |
| **⌥ Enter** in search, or **⌥**-click a result | Open the result alone: a Page with no chat, or a chat with its Page folded away |
| **⌥**-click a Page or a chat in the sidebar | Open it alone, without the chat or Page you had beside it |
| **⌘ ?** | Open the Help center. Works while the sidebar is open; with the sidebar collapsed, expand it first. |
| **⌘ \\** | Fold the navigation sidebar to a narrow strip, or pin it open again |
| **⌘ Enter** in **Ask a human** or **Share feedback** | Send the message |

## Undo and redo

| Shortcut | What it does |
| --- | --- |
| **⌘ Z** | Undo the last change you made to the Model in this browser tab |
| **⌘ Shift Z** (**Ctrl Shift Z** or **Ctrl Y** on Windows and Linux) | Redo the change you undid |

Undo and redo work anywhere in the app except while you are typing in a text field or the formula editor, while you are viewing a past version in version history, or inside a Page's text, where they undo and redo your typing instead. They cover only changes you made in this tab since it opened. To undo a change Ari made, or one from an earlier visit, use version history; see [Undo a change or restore an earlier version](/guides/undo-changes).

| Message | Meaning |
| --- | --- |
| **Changes undone** / **Changes redone** | The undo or redo finished. |
| **Couldn’t undo changes** / **Couldn’t redo changes**, with **Try again.** | The undo or redo failed, and the change stays as it was. |
| **Couldn’t undo changes** / **Couldn’t redo changes**, with **A later change edited the [field] of [subject], so this change can’t be [undone / redone] on its own.** | A later change edited one of the same fields, so nothing was undone or redone; undo that later change first. When later changes also edited other items this change touched, the notice adds **Later changes also edited 1 other item.** or **Later changes also edited [n] other items.** |

## Chat with Ari

| Shortcut | What it does |
| --- | --- |
| **⌘ /** | Start a new chat about the selected block. With no block selected and a Page open alone, with no chat beside it, the chat is about the selected cell, or about the open Page when no cell is selected. With a chat open, alone or with a Page beside it, the key works only with a block selected; otherwise it does nothing, so select **New chat** instead. |
| **⌘ L** | Mention the selected block, or the selected cell, in the current chat. With several cells selected, it mentions the first one. To mention a row or a column, right-click its name or header and choose **Mention in chat**. With text selected in one of Ari's answers, quote that text in your reply. |
| **⌥**-click a mention button (**Alt**-click) | Mention it in a new chat instead of the current one. Works on the button above a selected cell, the **@** in the formula editor, a Canvas block's **Mention in chat**, a Page's **Mention page in chat** in the sidebar, and **Add selection to chat** on selected text. |
| **Enter** | Send your message. While Ari is working, the message reaches Ari at its next step. |
| **⌥ Enter** | While Ari is working, queue your message for after Ari finishes. When Ari is not working, the key does nothing; use **Shift Enter** or **⌘ Enter** for a new line. |
| **Shift Enter** | Start a new paragraph in the message box. In a list, start the next item, or leave the list from an empty item. Inside code, insert a line break. |
| **⌘ Enter** | Insert a line break in the message box |
| **Esc** in the message box | Stop Ari while it is working |
| **Esc**, with the cursor outside the message box and not in a field, table, menu, or dialog | Stop following Ari |
| **Tab** or **→** in an empty message box | Use Ari's suggested reply |
| **A**, **B**, **C**, and so on | Choose an option on one of Ari's question forms, when the cursor is not in a text box |
| **↑** at the start of your draft | Move to the status line above the message box, such as a running sync. **↓** returns to the draft. |

## Pages and blocks

| Shortcut | What it does |
| --- | --- |
| **↑** / **↓** | Move through Pages in the sidebar, or through blocks on a Page |
| **→** / **←** | Expand or collapse a Page in the sidebar |
| **Home** / **End** | Move to the first or last Page in the sidebar |
| A letter or number | In the sidebar's Pages, move to the next Page whose name starts with what you type. Letters typed within 0.7 seconds of each other count as one name. |
| **Enter** or **Space** on a Page in the sidebar | Open the Page |
| **⌥ ↑** / **⌥ ↓** | Move the selected Page up or down among its siblings |
| **⌥ →** | Nest the selected Page under the Page above it |
| **⌥ ←** | Move the selected Page out one level |
| **F2** | Rename the selected Page |
| **Esc** | Cancel a Page rename in the sidebar and keep the old name |
| **Shift F10** or the **Menu** key | Move focus to the selected Page's buttons in the sidebar, starting with **New subpage** |
| **Enter** | Enter the selected block |
| **Esc** | Return from inside a block to the block |

## Table cells

| Shortcut | What it does |
| --- | --- |
| **Enter** | Edit the selected cell. While editing, save and move down. |
| Any letter, number, or symbol | Start editing the selected cell, replacing what it showed |
| **Shift Enter** | Save and move up |
| **Tab** / **Shift Tab** | Save and move right or left |
| **⌘ Enter** | Save and stay on the cell |
| **⌥ Enter** | Start a new line inside the cell |
| **Esc** | Cancel editing and return to the table |
| **Space** on a checkbox cell | Check or clear the checkbox of a true-or-false Variable |
| **Delete** / **Backspace** | Clear the selected cells' own values |
| **⌘ C** / **⌘ X** / **⌘ V** | Copy, cut, or paste the selected cells. What a copy carries, into a spreadsheet or back into a cfo.ai table, is explained in [Enter, paste, and clear values](/guides/enter-values#copy-cut-and-paste). |
| **⌘ Shift V** | Paste values only, without formulas |
| **⌃ ⌘ C** (**Ctrl Alt C** on Windows and Linux) | Copy the value a cell displays |
| **⌘ A** | Select every cell in the table |
| **Shift F10** or the **Menu** key | Open the right-click menu of the selected cell or header |
| **Shift**-click a row's or column group's chevron, or **⌘**-click on a Mac | Expand or collapse every sibling row or column group at that level. On Windows and Linux, use **Shift**-click; **Ctrl**-click does not do this. |

## Formulas and filters

| Shortcut | What it does |
| --- | --- |
| **Ctrl Space** | Open formula autocomplete |
| **⌥ F12** | Show the syntax and a description of the function under the cursor |
| **F2** | Start selecting a cell or row to reference |
| **Arrow keys** | In a cell's editor, with the cursor where a reference can go, point at the neighboring cell and insert its reference. After **F2**, move to the next or previous cell or row you can reference; **Tab** and **Shift Tab** do the same. |
| **Enter** | After **F2**, insert the selected reference. With the autocomplete list open, choose the highlighted item. Otherwise, save the formula and close the editor. |
| **↑** / **↓**, then **Enter** | In the autocomplete list, or in a filter's list of items, move through the list and choose the highlighted entry |
| **→** or **Tab** in a cell that shows its row's formula dimmed | Copy that formula into the cell so you can edit it. **Backspace** or **Delete** discards it. |
| **Esc** | Cancel reference selection, or close the editor without saving |
| **⌥ ↓** | Open the filters on the reference at the cursor |
| **F4** | Make the reference at the cursor absolute, or release it |
| **⌘ Enter** | In a row's formula editor, save and apply the formula to the parent rows too |
