Save a Skill when you repeat the same process and want Ari to follow it the same way every time, such as your monthly board update or your month-end review. A Skill is a named set of instructions that belongs to you. Ari uses it on its own whenever a request of yours matches the Skill's description, in every workspace where you are a member unless you limit it to one, so you save it once. Other people in your workspaces have their own Skills. For how Ari picks a Skill, see [Skills, Triggers, and Guides](/concepts/automation).

<Tabs>
  <Tab title="Ask Ari">
    Describe the workflow, paste instructions you already use, or attach a Markdown file, and ask Ari to save it:

    > Every month I send the board a one-page update with cash, burn, and hiring. Save that as a Skill.

    > Save the attached workflow as a Skill named weekly-cash-review.

    After Ari finishes a piece of work you want to repeat, you can also ask:

    > Save what we did here as a Skill.

    Ari picks a name and a description if you do not give them, and saves the Skill without a separate approval step. When the steps are built on this company's own accounts, systems, people, or figures, Ari limits the Skill to this workspace; otherwise the Skill applies in all your workspaces. To choose, say so: "Save that as a Skill for this workspace only." Ari confirms the name, when the Skill applies, and where; the Skill is listed in **Settings → Skills**. A new chat has the Skill at once, and a chat already open within a message or two.
  </Tab>
  <Tab title="By hand">
    <Steps>
      <Step title="Open Skills">
        Open the account menu, your name or picture at the bottom of the sidebar, choose **Settings**, and select **Skills**.
      </Step>
      <Step title="Start a Skill">
        Select **Write manually**. To have Ari write it with you in a chat instead, select **Build with Ari**.
      </Step>
      <Step title="Name the Skill">
        Enter a **Name**, such as `board-report`: lowercase letters, digits, and single hyphens. Spaces become hyphens as you type. You cannot change the name later.
      </Step>
      <Step title="Describe when it applies">
        In **Description**, say when Ari should use the Skill, starting with "Use when", such as "Use when the user asks for a board or investor report."
      </Step>
      <Step title="Write the instructions">
        In **Instructions**, type or paste the full workflow in Markdown: the steps, the structure of the result, and your conventions. The editor takes no file uploads, so paste a file's contents, or attach the file in a chat with Ari instead.
      </Step>
      <Step title="Choose where it applies">
        Under **Use in**, keep **All your workspaces**, or choose **Only in** this workspace for a procedure that fits only this company.
      </Step>
      <Step title="Save">
        Select **Create skill**. The Skill appears under **Your skills**, and Ari uses it in your chats wherever it applies.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Write a description that fits

Ari reads every Skill's description on each request to decide which Skill applies. Make the description specific enough that Ari does not use the Skill for unrelated requests, and broad enough to catch the different ways people ask for the same thing:

> Use when the user asks for a board update, investor update, or monthly summary for the board, or asks to prepare board materials.

## Update or remove a Skill

Ask Ari, for example "Update the board-report Skill to include a hiring section" or "Delete the weekly-cash-review Skill." Or open **Settings → Skills**, find the Skill with **Search skills**, and:

- Select **Edit**, change the **Description**, the **Instructions**, or **Use in**, and select **Save**.
- Select **Delete** and confirm. Ari stops using the Skill wherever it applied.

A Skill is yours, so a change or a deletion applies to your chats with Ari and nobody else's. **Settings → Skills** lists all your Skills, including ones limited to other workspaces. A Skill limited to a workspace you have left is not in use; you can still edit it, change **Use in**, or delete it. Built-in Skills cannot be edited or deleted; to change how one works for you, save your own Skill under a different name. A Skill of yours keeps its name when cfo.ai later ships an optional built-in Skill with the same name, for as long as the workspace leaves that built-in off. Once someone turns the built-in on, Ari follows the built-in in that workspace and sets your Skill aside there. Ari cannot change or delete a Skill under a built-in's name, so to keep your own version, save it again under a new name. See [Turn on a built-in Skill](/guides/turn-on-built-in-skills).

## Share a fact with your team

A Skill holds your own process. A fact everyone at a company should share, such as how the company defines bookings or when its fiscal year starts, belongs in workspace memory, which applies to every chat for everyone in that workspace. Ask Ari: "Remember for the whole workspace that bookings count signed contracts." See [What Ari remembers](/concepts/ari-memory).

## Start from a sample

[Sample Skills](/reference/sample-skills) has four complete Skills, such as a three-statement buildout and a headcount plan built from capacity, that you can save as they are or adapt.

## If something goes wrong

Settings explains why a Skill was not saved, for example when the name is already taken or the instructions are too long. For every message and limit, see [Settings](/reference/settings#skills) and [Limits](/reference/limits#skills-triggers-and-guides).
