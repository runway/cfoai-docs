---
title: "Work with dates"
---

Date references let formulas move through time, group dates, and calculate period boundaries.

<Warning>
  Several date functions described below (reading date parts, and building or diffing dates) are designed but not yet implemented in cfo.ai. Each section below is marked with its current availability.
</Warning>

## Use the table's granularity

Write Date with the grain used by the formula:

```text
Date.Month
Date.Quarter
Date.Year
```

Supported grains are Day, Week, Month, Quarter, Half, and Year.

## Reference a nearby period

The compact lookup uses the formula's current Date grain:

```text
Revenue[[-1]]
```

At monthly grain, this reads Revenue from the previous month. A positive value moves forward.

For an explicit shift, use `offset`, which is available today:

```text
offset(Date.Month, -1, "month")
```

Supported units are day, week, month, quarter, half, and year.

## Select a fixed period

```text
Revenue[Date.Month: "2026-01"]
Revenue[Date.Quarter: "2026-Q1"]
Revenue[Date.Year: "2026"]
```

## Find a period boundary — available today

```text
startofmonth(Date.Month)
startofquarter(Date.Month)
```

`startofday`, `startofweek`, `startofhalf`, and `startofyear` are also available. See [Date-truncation functions](/formulas/formula-reference/function-reference/date-truncation-functions).

## 🚧 Not yet available: read part of a date

```text
year(Date.Month)
month(Date.Month)
quarter(Date.Month)
half(Date.Month)
```

Week functions such as `weekday`, `weeknum`, and `isoweeknum` are also not yet implemented. See [Date-part functions](/formulas/formula-reference/function-reference/date-part-functions).

## 🚧 Not yet available: end-of-period and date-diff functions

```text
eomonth(Date.Month, 0)
datedif(`Start Date`, Date.Month, "M")
```

## 🚧 Not yet available: build a date

```text
date(year(Date.Month), 12, 31)
```

## FormulaRanges

Actuals and Forecast also depend on Date. A formula assigned to a FormulaRange must include Date in its scope.
