A Table Block shows your Model as a grid. When you want a trend line, a scorecard, or another visual a grid cannot express, ask Ari to build a chart or custom visual backed by live Model data.

<span id="what-a-code-block-can-be" />

## What a chart or custom visual can show

Ask Ari for any of:

- A **chart** — trend lines, bar comparisons, breakdowns over time.
- A **scorecard** — a headline number with a delta, like current-quarter Revenue against target.
- A **custom layout or interactive control** — a grid of stats, a small form, or another purpose-built view of your data.

## Live data, not a snapshot

A custom visual reads from named Model data views using the same Variables and Dimensions you would use to build a Table Block. The chart updates as its underlying Model values change.

A visual resolves its data in the Page's Scenario. Use a Table Block when you need a saved side-by-side Scenario comparison. See [Create and compare Scenarios](/scenarios/create-and-compare-scenarios).

<span id="update-a-code-block" />

## Update a chart or custom visual

Ask Ari to change an existing visual, its source values, or its title. Describe the intended result, such as switching from a line chart to stacked bars or narrowing the chart to one customer segment.

## Interactive controls and shared state

A custom visual can carry sliders, toggles, and other controls. While you drag a slider, the visual updates locally; the position is saved when you release it. Saved control positions belong to the Page's Scenario and are shared: a teammate viewing the same Scenario sees the slider where you left it, and switching Scenarios shows that Scenario's own positions.

A control never writes into your Model. To change a saved assumption, edit the Variable or the value in a Table Block, or ask Ari.

## Change a visual you did not build

There is no code editor for a custom visual. Hover the block and use **Select element** to point at the exact chart, number, or control you mean, then **Mention in chat** and describe the change to Ari. A blank block offers **Mention block in chat** so Ari can build it.

## When to reach for a Table Block instead

Use a Table Block when readers need the underlying numbers in rows and columns, such as a variance report or a detailed departmental view. Use a custom visual when the shape of the story matters more, such as a trend or a single headline measure.
