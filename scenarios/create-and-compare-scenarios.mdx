## Create a Scenario

Ask Ari to branch a new Scenario, for example: "Create a Scenario called Hiring Freeze off Main." Ari names it, sets its parent, and it starts as an exact copy of the parent at that moment.

Work inside a Scenario the same way you work in Main: update Variables, change formulas, add headcount, or restructure Pages. Nothing you do there changes Main until you merge it back.

## Compare Scenarios on a Table Block

A Table Block can show one or more Scenarios beside its baseline. Ask Ari to add a comparison, and choose:

- **Which Scenarios** to show alongside the baseline.
- **Layout** — compared Scenarios can sit in columns or in rows.
- **Measures** — the raw value, the delta, the percent difference, or some combination.

A Table Block compares across Scenarios or across time, never both at once. If a table is already set up to compare against an earlier period, adding a Scenario comparison replaces that time comparison.

## Ask Ari to compare without building a table

You don't need a saved Table Block to compare two Scenarios. Ask Ari something like "How does Operating Expense in the Hiring Freeze Scenario compare to Main for next quarter?" and Ari calculates both and reports the difference directly.

## Review before merging

Before bringing a child Scenario's changes into its parent, ask Ari what would change. Ari reports every Variable, formula, and value that differs so you can review the impact before anything moves into the Scenario your team relies on.
