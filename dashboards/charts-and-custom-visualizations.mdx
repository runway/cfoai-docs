A Table Block shows your Model as a grid. When you want a trend line, a scorecard, or another visual a grid cannot express, ask Ari to build a chart or custom visual backed by live Model data.

<span id="what-a-code-block-can-be" />

## What a chart or custom visual can show

Ask Ari for any of:

- A **chart** — trend lines, bar comparisons, breakdowns over time.
- A **scorecard** — a headline number with a delta, like current-quarter Revenue against target.
- A **custom layout or interactive control** — a grid of stats, a small form, or another purpose-built view of your data.

## Live data, not a snapshot

A custom visual reads from named Model data views using the same Variables and Dimensions you would use to build a Table Block. The chart updates as its underlying Model values change.

A visual receives each Variable's own kind of value: numbers, text such as a customer code or a currency, dates, and true/false values. A table of labels or invoice dates can drive a visual directly, without a numeric stand-in. An empty cell or a calculation error reaches the visual as no value.

A visual resolves its data in the Page's Scenario. Use a Table Block when you need a saved side-by-side Scenario comparison. See [Create and compare Scenarios](/scenarios/create-and-compare-scenarios).

## Start from a template

The **Browse Canvas block library** button in the chat composer opens the Canvas library. Select as many templates as you want; they join your message as chips. Each template is a recipe: some build one Canvas block, others a whole decision Page with its own assumptions and walkthrough. Your words decide what Ari builds from them, each on its own or one combined result whose parts read the same Model inputs, share one set of assumptions, and have one walkthrough. If a selected template is no longer available, the chat tells you which one instead of failing.

## Colors

A visual takes its colors from the app theme, so it follows your light or dark mode. If you ask for a fixed color, such as a brand hex code, Ari can use it. A fixed color keeps its value in both modes. When Ari saves the block, the save result names the fixed color and says that it will not follow the mode, so Ari can warn you if the result would be hard to read in one of them.

## Update a chart or custom visual

Ask Ari to change an existing visual, its source values, or its title. Describe the intended result, such as switching from a line chart to stacked bars or narrowing the chart to one customer segment.

A visual finds each series by the Variable's display name. If you rename a Variable a visual reads, ask Ari to update the visual in the same request: Ari's rename result names each Canvas block whose code still uses the old name, so it can fix the lookup instead of leaving the visual empty.

## Interactive controls and shared state

A custom visual can carry sliders, toggles, and other controls. Moving one changes your own view of the visual; it is a preview, not a saved change, unless the visual was built to save that value. Ask Ari to save a setting you want to keep.

A control never writes into your Model on its own. To change a saved assumption, edit the Variable or the value in a Table Block, or ask Ari.

## Change a visual you did not build

There is no code editor for a custom visual. Hover the block and use **Select element** to point at the exact chart, number, or control you mean, then **Mention in chat** and describe the change to Ari. A blank block offers **Mention block in chat** so Ari can build it.

## When to reach for a Table Block instead

Use a Table Block when readers need the underlying numbers in rows and columns, such as a variance report or a detailed departmental view. Use a custom visual when the shape of the story matters more, such as a trend or a single headline measure.
