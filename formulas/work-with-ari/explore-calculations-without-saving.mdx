---
title: "Explore existing calculations without saving"
description: "Ask Ari to inspect saved Model values, explain results, or validate a proposed formula without changing your workspace."
---

Ari can answer many financial questions by reading existing Table Blocks, saved formulas, connected sources, and Scenario history. Reading that information does not change your Model.

## Analyze what already exists

Examples:

> Explain the existing contribution margin by Department without changing anything.

> Compare the Revenue already shown by Region for the last six months. Do not change the table.

> Compare the saved Revenue and Headcount values in Main and Plan.

> Check whether Gross Margin behaves correctly when the table is segmented by Product.

Ari reads the relevant saved Model values and explains them in the context of the selected Date range, Dimensions, and Scenario.

## Review a formula before applying it

Ask Ari to draft and validate a supported formula change when you want to review the rule first:

> Draft a formula for Gross Margin, check whether it is valid, and wait for my approval before saving it.

Validation checks the proposed expression and target. It does not create a new calculated series or return values for a formula that has not been saved.

## When a new calculation is required

A result that depends on a new formula needs a visible saved Model row. If you ask Ari to produce that new calculation, Ari can create or reuse a row in a Table Block, save the rule, and inspect its results.

Use a Scenario if you want the saved analysis isolated from Main:

> Create a Scenario called Analysis, add Gross Margin by Department, and show the result without changing Main.

## Keep the requested output clear

Tell Ari which existing table, Variable, period, or Scenario to inspect. If a needed calculation is missing, Ari should explain the visible change required before creating it.
