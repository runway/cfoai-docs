cfo.ai pulls data from accounting, HR and payroll, CRM, payments, database, and file sources, and it lets Ari call other services through MCP servers and APIs. This page lists every source in the in-app directory, with the facts you need before you connect one. To connect a source, follow [Connect your accounting system](/guides/connect-accounting) or [Connect payroll, HR, CRM, payments, or a database](/guides/connect-other-sources). cfo.ai only reads from these systems; see [What cfo.ai does not do with your sources](#what-cfoai-does-not-do-with-your-sources).

## If your system is not listed

You can still bring its data in:

- Export a report from the system, such as a general ledger, a monthly profit and loss, or a payroll register, and [upload it as a CSV](/guides/upload-a-csv). An upload does not refresh, so upload a new export when the numbers change.
- Attach the export or workbook to a chat and ask Ari to load it or [import it as a model](/guides/import-a-spreadsheet-model).
- If the data sits in a database cfo.ai supports, such as PostgreSQL, connect the database.
- If the system has an MCP server or an API, [give Ari access to it](/guides/give-ari-another-service), so Ari can look things up live.

To ask for a system that is not listed, email [success@cfo.ai](mailto:success@cfo.ai) and name the system.

## Standard and premium integrations

Each integration that syncs data into your Model is standard or premium, and each one uses a connection slot on your plan. Your plan sets how many standard and premium connections you can hold; see [Plans and billing](/reference/plans-and-billing).

| Class | Sources | Plans |
| --- | --- | --- |
| Standard | Every integration on this page that is not marked premium, including QuickBooks Online, Xero, Rillet, Stripe (Direct), Gusto, Rippling, HubSpot, Salesforce, Shopify, and Google Sheets | Every plan that includes integrations |
| Premium | NetSuite SuiteAnalytics, every database and data warehouse, and the other sources marked "(premium)" on this page, such as Sage Intacct, Acumatica, Visma, Workday, Microsoft Dynamics 365 Business Central, and Amazon S3 | The Enterprise plan. A directory card for a premium source your plan does not include shows a **Premium** badge. |

These connections do not use a slot:

- CSV uploads.
- MCP servers and APIs that Ari calls live. If Ari saves a sync setup that copies an MCP server's or an API's data into your Model, that server or API then uses one standard slot.

Two rules change the count:

- Every Google Sheets connection in a workspace shares one slot. Each Google Drive connection uses its own.
- Each connection to a system uses its own slot, so a second QuickBooks company uses a second slot. A connection keeps its slot while it is broken or unfinished, until you remove it.

## How each kind of source connects

Most sources connect through Merge or Fivetran, outside services that copy a source's data for cfo.ai. A few connect directly.

| Method | Sources | What you do |
| --- | --- | --- |
| Sign in through Merge | QuickBooks Online, Xero, Gusto, Justworks, and the other HR and payroll systems that connect through Merge | Sign in to the system in a window cfo.ai opens, choose the company, and approve access. |
| Fivetran setup window | NetSuite SuiteAnalytics, Rippling, HubSpot, Salesforce, databases, and the other sources this page lists as syncing through Fivetran | Enter the credentials or sign-in the source needs in Fivetran's setup window. Some sources then show a table picker. |
| API key | Rillet | Paste a Rillet API key into the card. |
| Stripe app | Stripe (Direct) | Sign in to Stripe and install cfo.ai's Stripe app, which asks for read-only access. |
| Google sign-in and file picker | Google Sheets, Google Drive | Sign in with Google and choose files: one spreadsheet for Google Sheets, one or more files of any type for Google Drive. |
| File upload | CSV / Raw File Upload | Choose CSV files. Nothing to sign in to. |

When a sign-in asks for a permission you do not have, the person who administers that system must connect it, or grant you access first. See each source below for what it needs.

## Accounting

The app's **Accounting** filter also holds payment and commerce sources, such as Stripe (Direct) and Shopify, so they are listed here. In each table, a saved query is the query that brings a synced table into your Model; see [Saved query](/reference/glossary#saved-query).

### QuickBooks Online

| Fact | Detail |
| --- | --- |
| How it connects | Sign in to QuickBooks Online in a window cfo.ai opens (through Merge) and choose the company. |
| Standard or premium | Standard |
| What syncs | Monthly profit and loss and balance sheet, the chart of accounts, vendors, invoices, and journal entries |
| Saved queries cfo.ai adds | **QuickBooks Profit & Loss** and **QuickBooks Balance Sheet**. Each carries **Entity** and **Currency** columns. |
| History | From January 1 of last year through today. Ask Ari for a full-history import to reach back to a year you name, 2015 or later. A full-history import also takes the balance sheet of the month before that year. |
| First sync | Your three most recent complete months load first. The rest of the history loads in the background. |
| Nightly refresh | Re-reads the last three months, or the whole history when the connection has not synced for more than a month |
| Limits | One connection per company. Connect each company you own as its own connection. |
| You need first | A login with admin access to the company in QuickBooks Online |
| Writes back | No |

### Xero

| Fact | Detail |
| --- | --- |
| How it connects | Sign in to Xero in a window cfo.ai opens (through Merge) and choose the organisation. |
| Standard or premium | Standard |
| What syncs | Journals by month, the chart of accounts, tracking categories, contacts, and organisation details |
| Saved queries cfo.ai adds | **Xero Income Statement**, or **Xero Income Statement by Tracking Category** when you use tracking categories, and **Xero Balance Sheet**. Each carries **Entity** and **Currency** columns. The tracking-category statement has one row per journal line, so a line tagged in two categories counts once; each category gets its own pair of columns: **Tracking Category 1** and **Tracking Category 1 Option**, **Tracking Category 2** and **Tracking Category 2 Option**, and **Tracking Category 3** and **Tracking Category 3 Option**; the older **Tracking Category** and **Tracking Category Option** columns carry category 1. The balance sheet files each account on the side of the statement where Xero's own report shows it, so a credit card that Xero lists under liabilities counts as a liability. |
| History | From January 1 of last year through today. Ask Ari for a full-history import to reach back to a year you name, 2015 or later. |
| First sync | Your three most recent complete months load first. The rest loads in the background. Xero limits how many requests an app can make for an organisation each minute and each day, so a large ledger can take several hours or more than a day. |
| Nightly refresh | Re-reads the whole history window |
| Limits | One connection per organisation. Connect each organisation as its own connection. |
| You need first | A login with admin access to the organisation in Xero |
| Writes back | No |

### Document stores

Box, Dropbox, and SharePoint connect through Fivetran, and cfo.ai sets each connection up to copy every file in the folder you choose as it is. Ari can then list the folder and read any file in it up to the chat file size in [Limits](/reference/limits#chat-with-ari).

| Fact | Detail |
| --- | --- |
| How it connects | Fivetran setup window. You sign in to the source, then choose the folder. The window opens with **Replicate unstructured files** selected under file handling; keep that setting so Ari can read the documents. cfo.ai shows no table picker for these sources. Setup finishes when Fivetran reports the connection working. Until then, the page you return to offers **Continue in Fivetran**, and **Finish setup** on the connection reopens the same setup window. |
| Standard or premium | Standard |
| What it loads | Every file in the folder, in any format: PDFs, Word documents, spreadsheets, CSV files, and images. Ask Ari about them in a chat, for example "Read the signed contracts in the Sales Contracts folder of my Dropbox and check them against the sponsor schedule." Ari saves each file it reads in that chat, where it opens like a file you attached. A spreadsheet or CSV file becomes part of your Model when you ask Ari to import it, the same way as an attached file. |
| Refresh | Nightly and when you ask Ari. A file added to or changed in the folder appears after the next sync. |
| Who can read the files | Anyone who can see the connection. A person whose access to the connection is removed cannot list or read its files. |
| Limits | Ari reads a file up to the chat file size in [Limits](/reference/limits#chat-with-ari). ## What cfo.ai does not do with your sources

- cfo.ai does not write back to a synced source. To change a number in QuickBooks, Xero, or any other system, change it there; the next sync brings it in.
- cfo.ai does not connect bank accounts directly. Use your accounting system's balance sheet, upload bank transactions as a CSV, or connect Mercury's MCP server for live balances.
- The **Upload** button does not take Excel workbooks or PDFs. Attach them to a chat for Ari instead; see [Upload a CSV as a data source](/guides/upload-a-csv#excel-workbooks-and-pdfs).
- There is no **Sync now** button. Ask Ari to refresh a connection; see [Refresh data](/guides/refresh-data).

## Connections for Ari

MCP servers and APIs are tools Ari calls live when you ask a question, such as a bank balance in Mercury. Nothing from them is copied into your Model unless you ask Ari to save a sync setup, and they use no plan slot until then. The integrations above, by contrast, sync data into your Model once a day. Add an MCP server or API from the **MCP** and **API** tabs of the connection manager, or from **Settings → Connections**. See [Give Ari access to another service](/guides/give-ari-another-service).

### Any other MCP server or API

Use **Add with Ari** to have Ari research the provider and set it up in a chat, or **Add manually**. An MCP server can sign in with OAuth, a bearer token, or an API key header. An API needs an OpenAPI 3.0 or 3.1 specification and signs in with a bearer token, an API key header, a key as the Basic authentication username, or no authentication. A provider that requires an app registered with it in advance, and an API that signs in with a username and password or with a key in the address, cannot be connected this way.

cfo.ai's own MCP server, which lets an outside AI client use cfo.ai, is a different thing; see [Use cfo.ai from Claude Code, Codex, or another AI client](/guides/connect-an-ai-client).
