The cfo.ai app has a navigation sidebar on the left and the chat or Page you are working in beside it. This page describes each part in the order you meet it, starting with signing in, with every label and message. It describes a desktop browser; for phones and tablets, see [Phones and tablets](#phones-and-tablets). For keyboard shortcuts, see [Keyboard shortcuts](/reference/keyboard-shortcuts).

## Sign-in page

The page is titled **Sign in to cfo.ai**.

| Control | What it does |
| --- | --- |
| **Continue with Google** / **Sign in with Microsoft** | Signs you in with that account. When these are offered, the page reads **Choose how you want to continue.** |
| **Work email** | Your work address, with the note **Use the address where you want to receive cfo.ai workspace updates.** When only email sign-in is offered, the page reads **Enter your work email and we’ll send a six-digit code.** |
| **Send code** | Emails you a six-digit code and opens the code page. |

A Google or Microsoft sign-in that fails shows **We couldn’t complete sign-in. Please try again.**

### Sign-in code page

The page is titled **Enter your code**, with **We sent a six-digit code to [email].** Its footer reads **Codes expire quickly. You can request a new one if needed.**

| Control | What it does |
| --- | --- |
| Code boxes | The code is checked as soon as you type the sixth digit. |
| **Continue** | Checks the code. It stays off while the boxes hold a code that was already refused. |
| **Change email** | Goes back to the email step. |
| **Resend code** | Sends a new code and says **We sent a fresh code to [email].** |

When a Google or Microsoft sign-in matches an account that already exists, a code links the two sign-in methods. The page then says **We sent a six-digit code to [email] to safely link your sign-in methods.** and **This protects your existing cfo.ai account when adding another sign-in method.**, and offers **Start over** instead of **Change email**.

### Sign-in code messages

| Message | Meaning | What to do |
| --- | --- | --- |
| **That code does not match the one that was sent.** | The code is wrong. | Check the code, or check that you entered the right email. |
| **That code expired. A code works for 10 minutes after it is sent.** | The code is more than 10 minutes old. | Select **Resend code**. |
| **That code was not accepted. [n] codes were sent to this address in the last 10 minutes, and only the newest one works.** | You typed an older code. | Use the code in the newest email. |
| **That code was already used. A code works once.** | The code was used before. | Select **Resend code**. |
| **Too many wrong codes were entered, so that code no longer works.** | Too many wrong codes were tried. | Select **Resend code**. |
| **We couldn’t find the email for this verification step. Head back and start from the email step again.** | The sign-in lost track of your email. | Select **Start over**. |

For how many codes you can request and check, see [Limits and file types](/reference/limits#workspace-account-and-sign-in).

## Workspace search

Press **⌘ K** (**Ctrl K**) or select **Search** in the sidebar. Press **⌘ K** again or **Esc** to close it; a touch screen shows a close button. The box reads **Search pages, chats, and more**, and the window is marked **Preview**.

Search covers the Scenario the sidebar shows and lists only what you can open. It is not offered while you view a past version, or before you finish signing up.

### Before you type

The window lists the Pages you opened recently in this browser, under **Today**, **Yesterday**, **Past week**, and **Past 30 days**. The Page you have open is left out.

### Results

Results are grouped, up to eight in each group. The group with the best match comes first.

| Group | What it finds |
| --- | --- |
| **Pages** | Pages by title, and from two characters also by the words in their text. A Page found by its text shows the passage. |
| **Blocks** | Named tables, and titled charts and Canvas blocks |
| **Variables** | Variables that a table on one of your Pages shows |
| **Dimensions** | Dimensions that a table on one of your Pages shows |
| **Dimension items** | Items, such as a customer or a vendor, whose Dimension a table shows on its rows. Each names its Dimension and, for imported items, the connection it came from. |
| **Workspaces** | Your other workspaces, by name |
| **Chats** | Your chats by title. When none of the chats already loaded match, search also looks through your older chats once you pause typing. |

### How words match

- Every word you type must match.
- Case, accents, and punctuation are ignored: `paid in` finds Paid-In Capital.
- A word matches the start of a word: `rev` finds Revenue.
- From three letters, a word also matches inside a word: `count` finds Headcount.
- From five letters, a small typo is forgiven: `salry` finds Salary.

### Search keys and what a result opens

| Shortcut | What it does |
| --- | --- |
| **↑** / **↓** | Move through results |
| **Enter** | Open the result |
| **⌘ Enter**, or **⌘**-click | Open the result in a new browser tab |
| **Esc** | Close search |

A Page opens full-screen in the sidebar's Scenario. A block opens its Page, scrolls to the block, and flashes it. A Variable or a Dimension item opens the table that shows it and marks its row. A Page found by its text scrolls to the passage. A workspace switches to that workspace. A chat opens.

### Search messages

| Message | Meaning |
| --- | --- |
| **Type to search your workspace.** | Nothing typed and no recent Pages |
| **No results for “…”** | Nothing matched every word |
| **Loading pages…** | The Page list is still loading |
| **Couldn’t load pages. Try again from the sidebar.** | The Page list failed to load |
| **Searching dimension items…** / **Searching chats…** | A slower search is still running |
| **Couldn’t search dimension items.** / **Couldn’t search chats.** | That part of the search failed; the other results still show |

## Download spreadsheet

**Download spreadsheet**, the download icon in the Page header, exports the Page's tables as an Excel workbook. Its tooltip reads **Download tables as a spreadsheet**. cfo.ai has no button that downloads a Page as a PDF or a CSV; ask Ari for one. For what the workbook contains, see [Export a Page to Excel](/guides/download-a-spreadsheet); for a PDF, see [Get a PDF report or slide deck](/guides/get-a-pdf-or-slides).

While an export runs, the button spins and its tooltip shows the stage:

| Message | Meaning |
| --- | --- |
| **Waiting for another spreadsheet to finish** | Another export in this workspace is running; yours starts when it ends. |
| **Spreadsheet queued** | Your export is waiting to start. |
| **Preparing spreadsheet** | Your export is running. |

When it finishes:

| Message | Meaning |
| --- | --- |
| **Spreadsheet download started**, with the file name | The workbook downloaded. |
| **Spreadsheet download started**, with **[file]: [n] cells hold values instead of a formula. The Export notes sheet lists them.** and **Ask Ari to fix** | Some formulas could not be written as Excel formulas. **Ask Ari to fix** opens a chat that asks Ari to export the Page again and write a working formula into each of those cells. |
| **Could not download spreadsheet**, with **[Page]: [reason]** | The export failed. |

When you open a Page, it looks for your own newest export of that Page in that Scenario: one still queued or running, or one that ended within the last hour. It looks even when the Page no longer has a table, though a Page without a table shows no **Download spreadsheet** button, only the notices below. On a Page that still has a table, a running export makes the button busy again, with the tooltips above. When it finishes, the file downloads if this tab asked for it before a reload; an export that a closed tab, another tab, or Ari asked for is offered with **Spreadsheet ready** instead. An export that already ended shows one of these notices. A tab reports an export once, across its reloads, and a new tab reports it again:

| Message | Meaning |
| --- | --- |
| **Spreadsheet ready**, with **[file], requested at [time]** and **Download** | The export finished after you left, or another tab or Ari asked for it. Select **Download** to save the file; it does not download on its own. When some formulas could not be written as Excel formulas, the notice adds the cell count and the **Export notes** sheet, and **Download** then shows **Spreadsheet download started** with **Ask Ari to fix**. |
| **Could not download spreadsheet**, with **[Page], requested at [time]: [reason]** | The export failed after you left. |

A failed export's reason has up to three parts:

- **The export failed while [stage] and produced no workbook.** The stage is **starting**, **loading the saved model**, **reading the model calendar**, **calculating the page tables**, **calculating the inputs the page tables read**, **writing the workbook**, or **storing the workbook**.
- The cause, such as a formula whose input has no cell in the workbook, a formula that could not be written for Excel, **The export reached its time limit**, a Dimension whose list of items was larger than the export could read, or a table calculation that reached a limit: **A calculation in table "[table]" in scenario "[Scenario]" reached its 180-second time limit and was stopped before it finished.** or **A calculation in table "[table]" in scenario "[Scenario]" reached the [n] MiB memory limit of one calculation worker and was stopped before it finished.**
- When it is known, whether to try again: **The failure is temporary: a new export of the same pages can succeed.** or **A new export fails the same way while the saved model is unchanged.** A calculation that reached its time limit is not tried again, because the next export reaches the same limit; narrow the table, or ask Ari why it is large.

Two reasons stand alone:

| Message | Meaning |
| --- | --- |
| **Add a table to this page before downloading a spreadsheet.** | The Page's last table was removed during the download. |
| **The export was cancelled before it produced a workbook.** | The export was cancelled. |

For time and size limits, see [Limits and file types](/reference/limits#tables-pages-sharing-and-exports).

They appear under **New artwork**: **Choose an option, then publish it with your social copy.** Selecting one says **Option selected. Publish when it looks right.** If some fail: **Some covers could not be generated. You can use a ready option or generate new ones.** |
| **Public link** | **Anyone with this link can view the page. We do not list it publicly.** with the address and **Copy link** (**Link copied.**) |
| **Memorable address** | A readable address, such as `revenue-plan`, with **Update** (**Public address updated.**). **Optional. Memorable addresses can be guessed. Changing one retires the old address.** |

A memorable address has 3 to 64 lowercase letters, digits, or single hyphens between them; capital letters are made lowercase. Some words, such as `admin`, `docs`, `help`, `login`, `settings`, `share`, and `support`, are reserved.

| Message | Meaning |
| --- | --- |
| **use 3–64 characters: letters, numbers, or single hyphens between them** | The address breaks the rule above. |
| **this address is reserved** | The address is a reserved word. |
| **this address is already reserved** | Another link uses the address, or used it before it was retired. |

## Canvas blocks

### Canvas block controls

| Control | What it does |
| --- | --- |
| **Add** | At the block's top corner, for people who can edit the Page. Opens the Canvas block library to pick components and templates for Ari to add. |
| **Select element** | At the block's top corner. Click one part of the block to add it to the chat as a reference. |
| **Mention in chat** | At the block's top corner. Adds the block to the chat's message box. |
| **Inspect data** | At the block's top corner, on a block that reads Model data, for workspace admins only; its tooltip reads **Inspect the data behind this Canvas block**. Opens the **Canvas data** dialog, which shows each data view the block reads as its own read-only table. A table's header offers **Add to page**, which puts a copy of that table on the Page just before the Canvas block and then reads **Added to page**. The copy is an ordinary Table block, so you can edit it as you would any table; cells a connected system fills stay read-only there too. **Add to page** needs edit access to the Page and is unavailable in a historical view and for a view that reads another Scenario. |
| **Browse library** and **Mention block in chat** | On a blank block, under **Build something custom** and **Chat with Ari to generate custom visuals and interactive tools**. |

A blank block on a deleted Page that you open from version history reads **This Canvas block was empty when the page was deleted.**, and a blank block you cannot edit reads **This Canvas block is empty.**

A button inside a Canvas block can open another Page or block, put a message for Ari in the message box for you to review and send, or start a new chat that sends its message at once, such as a request to start a Guide. A button that hands work to Ari shows a trailing arrow. No button changes the Model.

A Canvas block can open your browser's own dialogs: a print button prints that block alone, and a block can ask you to confirm a step or type a short answer. These dialogs come from the block, not from cfo.ai. A Canvas block cannot show images from the web or from a file.

### Canvas block messages

| Message | Meaning | What to do |
| --- | --- | --- |
| **This Canvas block didn't start because its libraries failed to load.** | The block's software did not load. | Select **Retry**. |
| **This Canvas block didn't start because its runtime stopped with an error before it was ready.** | The block's software stopped before the block started. | Select **Retry**. |
| **This Canvas block was still starting after 15 seconds.** | The block's software is loading slowly. | Select **Retry**, or wait. |
| **This block failed to render.**, with the error | The block stopped with an error while drawing. | Select **Fix** to hand the block to Ari, or **Mention in chat**. |
| **This block's "[data]" data didn't load because the connection to cfo.ai failed.** | Your connection to cfo.ai failed. | Wait. The block asks again when your connection returns. |
| **This block's "[data]" data failed to load.** | The data the block reads failed to load. | Select **Mention in chat** and ask Ari to check the data the block reads. |
| **This Canvas block no longer exists in this scenario.** | A saved change deleted the block after the Page loaded. | Nothing. The block leaves the Page when it next loads. |

A block that stopped with an error tries again by itself once after 2 seconds, and any block that did not start tries again when your connection to cfo.ai returns.

## Phones and tablets

A phone or tablet browser opens the same workspace in a reading layout, one screen at a time. A tablet gets the desktop layout only when its browser asks for the desktop site.

| Control | What it does |
| --- | --- |
| **Open navigation** | Opens a drawer with the logo, **Search**, your chats, the **Model** section with its Pages, and **Connections**. Picking a chat, a search result, or **New chat** closes it; so does **Close navigation**. |
| **Open page panel** | In a chat's header. Opens the Page beside the conversation. |
| **Back to chat** | On a Page opened from a chat. Returns to the conversation. |
| **New chat** | On a Page. Starts a chat. |

Pages are read-only in this layout, whatever your access. You can read tables and Canvas blocks, and a table's **Table block settings** menu offers **Show formula bar** and **Show formula columns**, but you cannot edit cells, add rows or blocks, or create Pages or Scenarios. The Page header shows only the Page's name: **Share**, **Download spreadsheet**, and **Version history** are not offered. Empty states say **Pages are read-only in this browser. Use Desktop Site to create a page.** and **Scenarios are read-only in this browser. Use Desktop Site to create one.**

To edit on a phone or tablet, ask your browser for its desktop site. You get the full desktop app, editing included.
