This page lists every size, count, and time limit in cfo.ai, grouped by part of the product. Each section ends with links to the pages that explain its limits. For what each plan includes, such as integration slots and AI usage, see [Plans and billing](/reference/plans-and-billing).

## Chat with Ari

| Limit | Value |
| --- | --- |
| Files attached to one message | 50. A larger selection attaches the first 50 in the order you picked them, and the notice names up to three of the rest. |
| Size of one image file | 10 MB |
| Size of one other file, such as a PDF, Excel workbook, ZIP, CSV, or text file | 500 MB |
| Quoted excerpts in one message | 5, each up to 2,000 characters |
| Size of a picture shown to Ari | 3.75 million pixels. A larger image is scaled down before Ari sees it, and Ari can reopen a part of an image enlarged up to 4 times, within the same ceiling, to read small text. An image of more than 25 million pixels cannot be opened as a picture at all, whole or in part. |
| Images Ari looks at directly in one turn | 21 MB in all. Ari opens every attached file in its private workspace; an image it opens is also shown to it as a picture until the turn's 21 MB is used, and after that it reads the file in the workspace. When one request would carry more than 20 images, an image wider or taller than 2,000 pixels is not shown; Ari reads it in the workspace instead. |
| Size of a PDF whose text Ari reads | 100 MB. Ari reads a PDF as the text of its pages, not as a picture. One read returns as many pages as fit in 100,000 tokens, and Ari reads the later pages from a text file in its workspace. Ari can turn a page with no text, such as a scan, into a picture and look at it. A PDF over 100 MB, up to the 500 MB you can attach, still opens in Ari's workspace, but the read returns no text for it and tells Ari why. |
| Size of a CSV attached in a chat that can become a data source | 500 MB, the same as any other file. The file's name must end in `.csv`, and the file must not be empty. |
| Recipients of one email Ari drafts | 10. On an email with Cc, the To and Cc addresses together count toward the 10, each address once |
| Size of a page of conventions you ask Ari to remember | 32 KiB of text, saved as up to 12 separate facts at a time |
| Files Ari delivers at once | 10, each up to 50 MB, and 250 MB in all |
| Time a download link for a file in a chat works | 5 minutes after you select the file; select it again for a new link |
| Table Ari posts in Slack as a Slack table | The first table in a message, up to 100 rows, 20 columns, and 10,000 characters of cell text; a larger or later table, and a table inside a code block, posts as text, and a message whose text around the table is too long for Slack posts whole as text |
| File Ari posts in Slack, with a message or alone in a Slack conversation with Ari | 1 for each message or post, a file of any type saved in a chat, with no size limit beyond the chat's own; an empty file is refused. When a file sent with a message does not go through, the message is not sent, and when a file sent alone does not go through, Ari's reply still posts. An upload stops when no bytes move for 15 seconds. Text sent in one message with a PNG, JPEG, or GIF image, as a heading above it, holds up to 3,000 characters, counted with each link's full address. See [Ari in Slack](/reference/chat#ari-in-slack) |
| Length of one Slack message from Ari | 40,000 characters, the most Slack shows of one message; some characters, such as most emoji, count as two. Longer text posts whole, as consecutive messages in the same place and in order. Each message but the last ends after the last paragraph break that fits, or else the last line break, or else the last space, outside a code block, a link, and a mention; text with no such place to break is cut at 40,000 characters. See [Ari in Slack](/reference/chat#ari-in-slack) |
| Earlier Slack messages Ari reads with a channel message | Up to 30. In a thread, the 30 newest earlier messages of that thread, leaving out the ones the conversation already read. At the channel's top level, the 30 most recent top-level messages. For each of those whose thread Ari answered in, Ari also reads its own most recent replies there, which do not count toward the 30. To find these messages, cfo.ai goes through a whole thread, whatever its length, so a long thread still gives Ari its newest messages and no more than 30 of them. See [Add Ari to a channel](/guides/use-ari-in-slack#add-ari-to-a-channel) |
| Workspace memories Ari reads when it decides whether to reply to a Slack channel message | Up to 12, the closest matches to how Ari takes part in Slack, each up to 600 characters, and 6,000 bytes of text in all; a longer memory is cut at 600 characters. Private memories are not read for this decision. Once Ari has started on the message, it can read the private memories of the person who wrote the message. When saved memory does not answer within 5 seconds, Ari decides from the messages alone. See [Tell Ari when to reply in a channel](/guides/use-ari-in-slack#tell-ari-when-to-reply-in-a-channel) |
| Time Ari can spend writing one action before the action is cancelled | 3 minutes, counted from when Ari starts writing it; Ari then continues the reply, and a second action cancelled this way in the same reply ends the reply. See [When Ari takes too long to write one action](/reference/chat#when-ari-takes-too-long-to-write-one-action) |
| Time a reply waits while auto-reload buys AI usage | No fixed limit; the reply continues when the usage arrives, or stops when the purchase fails. See [Notices in the chat](/reference/plans-and-billing#notices-in-the-chat) |
| Length of a paste that stays text in the message box | 10,000 characters. A longer paste becomes a **Pasted text** card; see [The message box](/reference/chat#the-message-box) |
| Length of one message | No fixed limit. When the messages Ari takes in one turn are too long for it to read in one request, cfo.ai saves the longest one as a file with the chat, then the next longest, until the rest fit, and Ari reads each saved message from its file. A message is refused only when it is still too large, for example because its text could not be saved this way; see [When a reply stops early or shows an error](/reference/chat#when-a-reply-stops-early-or-shows-an-error) |
| Length of one chat | No fixed limit; when a chat grows too large for Ari to read in one request, Ari summarizes its earlier messages and continues the reply. |

See [Attach files to a chat](/guides/attach-files) and [Chat controls and messages](/reference/chat).

## Connections, syncs, and uploads

| Limit | Value |
| --- | --- |
| Size of a CSV uploaded as a data source | 500 MB, in a `.csv` file, with up to 16 MiB in one row |
| Size of a connected Google Sheet | 50 MB, read as an Excel workbook |
| Tabs a background first import of a Google Sheet builds in a step of their own | 48. The import holds up to 50 steps, and two of them read the workbook and report the tie-out. With more visible tabs, neighboring tabs share a step; see [Workbook imports](/reference/imported-data#when-a-workbook-import-stops) |
| Size of an Excel or CSV file read from Google Drive | 500 MB, the same as a file attached to a chat; a CSV becomes a data source only up to 50 MB |
| Tables one connection syncs | 100, for sources with a table picker |
| Time a connect link works, for someone else to connect a source | 7 days, or until someone finishes it or it is turned off |
| Sources in one connect link | 10. A link that asks for an API key carries one API and no other source, and saves one connection. |
| Connect links Ari turns off in one request | 50 |
| Time cfo.ai waits for a provider's own first sync, for a later sync the provider is still running after 45 minutes, or for a later sync Fivetran rescheduled to a later time | No fixed limit while the provider keeps reporting the sync unfinished. cfo.ai checks every 10 minutes and stops waiting only after 20 hours with no such report; the data from the last sync cfo.ai loaded stays as it is meanwhile |
| Time to plan a saved query | 40 seconds |
| History in the first load of QuickBooks Online or Xero | From January 1 of the previous year; the 3 most recent complete months arrive first |
| Months the nightly refresh of QuickBooks Online reads again | The last 3, plus the older months of a fiscal year whose net income no longer matches the balance sheet, plus the balance sheet of any older month an earlier refresh still owes; ask Ari for a full-history import to correct other months |
| History in a full-history import of QuickBooks Online or Xero | Back to 2015 at the earliest |
| Rillet connections in one workspace | 1 |
| Start of the nightly refresh of connected sources | 02:00 UTC; each workspace's connections start at the workspace's own fixed point within the following hour |
| Answer Ari gets from a connected API | No size limit of its own. A request fails when the API sends nothing for 20 seconds, before its answer starts or partway through, and Ari then gets no partial answer; the time cfo.ai takes to save an answer does not count. An answer that arrives whole is never shortened. A file, such as a PDF, is saved to the chat as an attachment, and so is a JSON or text answer too long for Ari to read at once, which Ari then reads from the saved file. cfo.ai retries a save that failed because storage was briefly unavailable, until storage has accepted nothing for 30 seconds. When an answer of 4 MiB or less is still not saved as a file, Ari still gets all of it: the whole answer stays in the chat's history, where Ari reads it in parts. When a longer answer is still not saved, the call fails and tells Ari the response could not be saved; the request ran once and is not sent again. An answer that cannot be saved whole saves no partial file. A program Ari runs can read a saved answer of up to 64 MiB |
| Rows Ari reads from a connection's synced data | No row limit, and no pages, for Ari in a chat. One read returns every row of a synced table, of a saved query, or of SQL Ari writes, and every table, column, and file of a listing. Rows too long for Ari to read at once are saved to the chat as a file, which Ari then reads, and a program Ari runs receives every row. cfo.ai waits for as long as the warehouse computes the result; once rows are arriving, 15 seconds without a row ends the read, and one hour ends any read. A read of an uploaded file's rows, or of a table that a source Ari fetches loaded, returns up to 50 MB, and Ari reads a larger result through the warehouse. A connected AI tool has no chat to save a file in, so one read of a saved query returns up to 50 MB and a larger result is refused; see [The cfo.ai MCP tools](/agents/mcp-tools) |
| OpenAPI 3 or Swagger 2.0 definition for an API connection | An address that answers within 20 seconds, fetched over `https` (an `http` address is tried at its `https` address), with a document of 12 MiB or less; a definition pasted with **Paste JSON** in Settings takes the same 12 MiB, and one Ari supplies inline, in a chat or as `spec_json` over MCP, is limited to 64 KiB |
| Time one load of a saved query's result can go without progress | 15 minutes, on each of its three attempts. A load has no fixed time limit: the 15 minutes start over with each row cfo.ai reads from the result, and the time the warehouse takes to compute the query does not count. A load that stalls is tried again, and its failure names the stall and the attempt |
| Times an import stopped for low worker memory runs again | 3. Imports and spreadsheet exports share a worker, and the worker stops its imports when less than 10% of its memory is free. A stopped import waits about 1 minute, then about 2 minutes, then about 30 minutes, each up to 20% shorter or longer, and runs again; a fourth stop fails it. A stop for low memory does not use up one of the import's other attempts, such as the three attempts of a saved query's load |
| When the nightly refresh runs a connection's saved queries | When every one of the workspace's sources has finished syncing, or at the four-hour cutoff for the sources that have; a source still syncing at the cutoff gets its queries within about two minutes after its sync ends, checked for up to 20 hours |
| Time one run of a sync setup for an MCP server or API can take | 10 minutes. A replace or snapshot sync without a changes-since filter that reaches the limit after saving at least one page runs again at once from its last saved page, for as many 10-minute runs as it needs; an upsert, append, or changes-since sync gets one run |
| Time one sync of a connection's sync setups can take | No fixed limit while the sync makes progress. An attempt stops when it makes no progress for 1 hour, and a sync gets three attempts; a finished setup and each page or answer the source sends count as progress. The setups run one after another, and a later attempt skips the setups already finished |
| Results one sync of a sync setup can save | 10,000 pages for every sync, counted across its runs, each page one source response of up to 1 MiB from an API or 2 MiB from an MCP server. A replace or snapshot sync without a changes-since filter saves page by page; an upsert, append, or changes-since sync holds its whole result, up to 16 MiB in all |
| Size of one page an MCP server returns to a sync setup | 2 MiB |
| One request for a page from an MCP server | No limit of its own in a sync: connecting, listing the server's tools, and the call can each take the time left in the setup's 10-minute run. When Ari reads a setup's first page to check or repair it, each of the three gets 45 seconds. A time limit named in the tool's own description is the server's own |
| How often cfo.ai fetches a source that has no integration | Once a day, when the nightly run starts at 02:00 UTC or at the connection's own time of day; ask Ari to fetch again for newer data sooner |
| Fetches of one source that has no integration at a time | 1; a fetch asked for while another runs does not start |
| Time to enter a sign-in code that such a source sent you | 15 minutes from when the fetch asked for it; a code is 4 to 12 letters and digits |
| Public API addresses in one source Ari builds from public data | 8 |
| Size of one file a fetch delivers | 50 MiB |
| Redirects a fetch follows to a host outside the source's own domain | 3, each as a plain download that carries no login, key, or cookie |

See [How imported data loads](/reference/imported-data) and [Integrations directory](/reference/integrations).

## Tables, Pages, sharing, and exports

| Limit | Value |
| --- | --- |
| Items on one table axis before Ari notes that the table may be slow | About 1,000 |
| Scenarios one Canvas block can read | No fixed limit. A block can compare four or more Scenarios. |
| Datasets one Canvas block can read | No fixed limit. A dataset is one live read of Model data that the block draws from, and each one is one more calculation. |
| Size of a Canvas block's source | No limit. Pictures embedded in the block are part of its source. |
| Calculated data a Canvas block can read and still be checked by Ari | No limit for the block as a whole; one dataset can read up to 256 MiB. Ari checks a saved block by rendering it in a browser. It does not render a block with a larger dataset, and it reports that the block's render was not observed; the other blocks in the same check still render. A render is not cut off at a fixed total time: it ends with an error when it makes no progress for 30 seconds. See [How Ari checks a visual](/concepts/pages-and-blocks#how-ari-checks-a-visual). |
| External links on one Page | 100 |
| Pages one share link opens | 50, across all its Scenarios. A Page counts once for each Scenario the link opens it in, so a Page shared in three Scenarios counts as 3. A link has no separate limit on Scenarios. |
| Length of a share link's name | 80 characters, on one line |
| Links on a Page before **Find a link** appears in the Share panel | More than 5 |
| Length of a share link's memorable address | 3 to 64 characters: lowercase letters, digits, and single hyphens |
| Pages in one workbook Ari exports | No fixed limit. The export's calculation allowance and the workbook size limit, both in this table, still apply, and the **Export notes** sheet names the Pages they leave out |
| Spreadsheet exports a workspace prepares at once | 1. Another export is never refused: it waits in the queue and starts when the one before it ends. Your second request for the same Pages in the same Scenario, format, and saved version, with the same periods showing in the Page's Canvas blocks, joins the export that is already queued or running. [Export a Page to Excel](/guides/download-a-spreadsheet) says how Ari cancels one |
| Time one spreadsheet export can run | No fixed limit while it makes progress. The one time limit is on a stall: an export that makes no progress for 90 minutes stops; each stage it enters, each calculation answered, and each Page calculated starts the 90 minutes over. Time waiting in the queue does not count. An export stopped this way fails and is not run again by itself; see [Export a Page to Excel](/guides/download-a-spreadsheet#when-an-export-leaves-pages-or-formulas-out) |
| Time a spreadsheet export keeps running while its worker is low on memory | About 60 seconds: the export stops after twelve checks in a row, 5 seconds apart, that find less than 10% of the worker's memory free. The worker also runs imports and other exports, so another job may be the one using the memory. An export stopped alone fails and is not run again by itself. When one check stops two or more exports, each runs once more by itself, about 5 seconds later; an export runs at most twice, so a second stop fails it. [The cfo.ai interface](/reference/interface#download-spreadsheet) has its message |
| Time **Recent exports**, on the Share panel's **Export** tab and in the **Download spreadsheet** menu, lists your past exports of a Page | 24 hours after you asked for each one, up to 10 of them, for this Page and Scenario; an export still queued or running is always listed. A share-link reader's file can be downloaded for a shorter time: only while the Page still shows that reader what the file holds, after which its row reads **Out of date**; see [A share-link reader's file](/reference/interface#a-share-link-readers-file) |
| Time Ari can find your own newest export of a Page selection in a Scenario without starting one | While it is queued or running, and for 1 hour after it ends; an export of the same Pages in another Scenario is not found |
| Size of one calculated table an export reads | 64 MiB for one read, and 256 MiB for all of an export's reads together. An input, which is a table the export calculates only so that formulas can refer to it, is left out when it exceeds either limit or when the calculation engine stops it at its own time or memory limit, and the cells that read it keep their calculated values; a Page's own table that exceeds either limit fails the export. When the tables and their inputs together pass the workbook size limit, the workbook is written once more without the **Model inputs** sheet |
| Time one table calculation can run | 180 seconds; a calculation that reaches it is stopped, and retrying runs into the same limit. An export whose table reaches it while its formulas are worked out writes that table as values instead of failing; see [Export a Page to Excel](/guides/download-a-spreadsheet#when-an-export-leaves-pages-or-formulas-out). A calculation that outlasts one browser request keeps running, and the table, Canvas block, or chart keeps its loading state until the result arrives |
| Time Ari waits for one calculation of its own | 239 seconds, for a table, Page, Canvas, mapping, or validation read, so a 180-second calculation reaches Ari in the same call; Ari's other tools wait 60 seconds. A wait that ends does not stop the action: the action keeps running, Ari is told it is still running, and its whole result is saved as a file with the chat for Ari to read when it ends. **Stop** does not end an action whose wait has already ended, so a change it was making finishes |
| Length of a formula in an exported workbook | 8,192 characters, Excel's limit; a longer formula is exported as its value |
| Size of one exported worksheet | Excel's 1,048,576 rows and 16,384 columns. A saved table that needs more is refused before anything is calculated, and a sheet may hold more than a million data cells when it fits |
| Size of an exported workbook | 256 MiB of sheet content before compression, and 128 MiB as the `.xlsx` file; the supporting formula rows and the **Export notes** sheet each have their own allowance of 1,000,000 cells |
| Cells one export calculates | 6,000,000 across the workbook, in up to 1,024 calculation requests. When the allowance runs out, the workbook keeps the Pages that finished: the Page whose tables were still calculating is left out, and so are the Pages after it. An input the export did not reach is left out, and the cells that read it keep their calculated values. An export whose first Page with a table did not finish fails |
| Series one exported chart block can draw in Excel | 255, Excel's limit; a chart with more is left out of the workbook with its data, and **Export notes** says so |
| Length of a text you edit in place in a Canvas block | 2,000 characters on one line; the editor counts from 1,800 and saves nothing past 2,000. See [Text you can edit in a Canvas block](/reference/interface#text-you-can-edit-in-a-canvas-block) |
| Blocks whose view settings one browser remembers, such as a table's height, whether it is collapsed, open panes, and expanded rows | 200 per browser, across workspaces; past that, the block whose settings were saved longest ago forgets them first |

See [Export a Page to Excel](/guides/download-a-spreadsheet), [Share a Page outside your workspace](/guides/share-a-page), and [Table block controls and messages](/reference/table-blocks).

## Skills, Triggers, and Guides

| Limit | Value |
| --- | --- |
| Saved Skills for one person, across all their workspaces | 100, copies a teammate shared included |
| Workspace Skills, shared by everyone in one workspace | 100 |
| Length of a Skill's name | 64 characters: lowercase letters, digits, and single hyphens |
| Length of a Skill's description | 1,024 characters |
| Length of a Skill's instructions | 49,152 characters |
| Length of a Trigger's name | 200 characters |
| Length of a Trigger's instructions | 10,000 characters |
| Length of a run's report of its outcome, and of a decision a Trigger waits on | No fixed limit. A decision longer than one Slack message arrives as consecutive messages; see [Chat with Ari](#chat-with-ari) |
| Time a reconnect link in a run's message works | 7 days; it opens only for a member of the workspace who signs in |
| Precision of a Trigger's schedule | 1 minute, on the clock of the Trigger's time zone. A local time the spring change skips runs at the first minute after the gap, and a local time the autumn change repeats runs once. A Trigger saved without a time zone runs in UTC. |
| Time a one-time Trigger keeps trying to start after its date and time | 24 hours, with attempts from once a minute to once an hour; then it pauses |
| Runs in a row that end without finishing the task and without a message to you before a Trigger pauses itself | 3 |
| Time a download link in a scheduled run's message works | 24 hours |
| Cells Ari writes when it fills your own workbook with the **Workbook template fill** Skill | Input cells, with a number, text, a date, or a yes/no value, and a new formula in a cell that holds none. Ari does not write a cell that already holds a formula, a cell inside merged cells other than the top-left one, a cell an array formula fills, or a new heading for an Excel table's column; a fill that names one writes nothing. The copy keeps the workbook's formatting, charts, images, sparklines, comments, print settings, and other sheets. A copy that Ari also adds sheets to can lose its charts and images |
| Formula cells in a workbook Ari filled | Hold the results Ari calculated: the Skill has Ari recalculate the copy before it delivers it, so Excel's Protected View and file previews show the numbers. A copy that Ari could not recalculate holds no stored results, and those cells show empty until Excel, Google Sheets, or LibreOffice opens the copy for editing |
| Where Ari reads the template for a later fill | The Skill that holds the mapping, when the template is saved with it: Ari opens the template when it runs that Skill in the workspace the template was uploaded in, for you and for anyone who has the Skill there, even after the chat you attached it in is deleted. When the template is not saved with the Skill, Ari reads it from the chat you attached it in; after that chat is deleted, attach the workbook again and ask Ari to update the Skill |
| Files a Skill can carry | Files a person uploaded, in the workspace they were uploaded in, that the Skill's instructions refer to and that the same person saved there. Not files Ari made, and not copies of a connected Google Sheet. See [Files saved with a Skill](/concepts/automation#files-saved-with-a-skill) |
| Saved Guides in one workspace | 200 |
| Length of a Guide's name | 64 characters: lowercase letters, digits, and hyphens |

See [Save a workflow as a Skill](/guides/save-a-skill), [Schedule a report or a reminder with a Trigger](/guides/schedule-a-trigger), and [Walk someone through a Page with a Guide](/guides/create-a-guide).
