Use a share link when someone outside your workspace needs to read a report, such as a board update or a cash forecast. The link opens the Page read-only, without a sign-in or a cfo.ai account, in the Scenario you choose. Everyone inside your workspace can already open every Page, so you do not need a link for teammates.

<Tabs>
  <Tab title="Ask Ari">
    Ask Ari for a view-only link and name the Page:

    > Create a view-only link to the Board summary Page.

    Ari returns the link's address. To have one link open several Pages, name them all. The Page you name first is where the link lands, and every Page opens in the Scenario your chat is in:

    > Create a view-only link to the Board summary Page that also opens the Cash forecast and Headcount plan Pages.

    Creating a link does not change the Model. Ari cannot add a password, give the link a memorable address, or turn a link off; do those in the **Share** panel.
  </Tab>
  <Tab title="By hand">
    <Steps>
      <Step title="Open the Page in the right Scenario">
        Open the Page you want to share. A new link shows the Scenario you are viewing, so pick it first in the sidebar's Scenario picker.
      </Step>
      <Step title="Open the Share panel">
        Select **Share** in the Page header. The panel's title names the Page, so you can confirm you are sharing the right one.
      </Step>
      <Step title="Add more Pages, if you want them">
        Under **Pages to share**, select each other Page the link should open. The Page you started from is marked **Opens here**; readers land on it. One link opens up to 50 Pages.
      </Step>
      <Step title="Create the link">
        Under **External access**, select **Create link**. The new link appears with its **Link settings** open.
      </Step>
      <Step title="Change the Scenario or add a password, if you want">
        In **Link settings**, choose another Scenario with **Shared scenario**, or turn on **Require password**. Turning on the password fills in a generated password; type your own instead if you prefer. Select **Save changes**. Saving gives the link a new address, so copy it after you save.
      </Step>
      <Step title="Copy the link">
        Select the copy button on the link (**Copy external link**) and send it to the reader. Send a password separately from the link.
      </Step>
    </Steps>
  </Tab>
</Tabs>

The link works for anyone who has it until you turn it off, and cfo.ai does not list it publicly. It never lets the reader edit anything. To see exactly what a reader can and cannot see, read [Sharing and access](/concepts/sharing-and-access).

## Change a link's Scenario or password

1. Open the Page and select **Share**.
2. On the link, open **Link settings**.
3. Change **Shared scenario**, turn **Require password** on or off, or select **Generate password** for a new one. **Show password** displays the current password.
4. Select **Save changes**.

Saving replaces the link: the old address stops working, people who opened the Page through it lose that access, and the new address is shown in its place. Send the new address to everyone who should keep reading.

## Give the link a memorable address and a preview

A link without a password gets a short public address and a preview card. The card is the picture, headline, and description that chat and social apps show when someone pastes the link. cfo.ai writes the first preview from the Page. The card names cfo.ai unless an administrator turns on **Show the brand on link previews** in **Settings → General → Brand**; see [Brand your workspace](/guides/brand-your-workspace#who-sees-the-brand).

1. On the link, select **Edit share preview**.
2. Edit the card's **Headline** and **Description**. For a different picture, select **Create new artwork** and choose one of the three options it makes.
3. Select **Publish changes**.
4. To give the link a readable address, type it under **Memorable address**, such as `board-update`, and select **Update**. **Copy link** copies the address.

A memorable address can be guessed, so use a password-free link only for Pages you are happy for anyone with the address to read. Changing the address retires the old one. A link that needs a password has no memorable address or preview to edit; its password prompt shows your brand when **Show the brand on link previews** is on.

## Turn a link off

1. Open the Page and select **Share**.
2. On the link, select **Turn off external link** (the trash icon).
3. **Also remove access already granted by this link** starts checked, so everyone who opened the Page through the link loses access too. To let them keep their access, clear it.
4. Select **Turn off link**.

Every message in the **Share** panel, and what a reader sees when a link is off or needs a password, is listed in [The cfo.ai interface](/reference/interface#share-panel).
