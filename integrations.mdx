cfo.ai connects to the systems where your financial and operational data already lives, so your Model stays current without manual entry.

## File upload

**CSV / file upload** is a manual option for bringing in a raw file directly. Use it when a live connection is not set up yet, or for a one-off or specialized report a system does not sync automatically.

## Accounting and ERP

- **QuickBooks Online**
- **Xero**
- **NetSuite SuiteAnalytics** (via Fivetran)

Use an accounting or ERP integration when you want Actuals to update automatically each time your books close.

## HR

- **Rippling** (via Fivetran)

Connect Rippling to bring headcount, compensation, and other people data into your Model alongside your financials.

## Spreadsheets

- **Google Sheets** (via Fivetran)

Use a Google Sheets connection when a Variable or driver is still maintained in a spreadsheet outside your other systems.

## Databases

- **PostgreSQL** (via Fivetran)
- **Amazon RDS for PostgreSQL** (via Fivetran)
- **Amazon Aurora PostgreSQL** (via Fivetran)
- **Google Cloud SQL for PostgreSQL** (via Fivetran)

Use a database connection when your data lives in a system of record that does not have a dedicated integration above, but is reachable through one of these PostgreSQL-compatible sources.

## Connections for Ari

The integrations above bring data into your Model as Actuals. Separately, cfo.ai has a **Connections** area where you can link external tools and services for Ari to work with directly, browsable through an **MCP** tab and an **APIs** tab. As of this writing, everything here is available to connect but nothing is connected yet — each item has its own **Connect** button waiting to be clicked.

### MCP

Browsable by category:

- **Payments** — Stripe, PayPal, Square, Mercado Pago
- **Banking & Spend** — Mercury, Ramp, Brex, Expensify, Plaid
- **Accounting & Tax** — Avalara AvaTax, Avalara Returns, Numeric
- **HR & Payroll** — Gusto, Deel
- **Equity & Compliance** — Carta, and others
- **Productivity & Docs** — Notion, Linear, Asana, Atlassian (Jira and Confluence), Airtable, monday.com
- **Data & Analytics** — Google BigQuery, Supabase, ThoughtSpot

If you don't see what you need, use **Add server** or the search bar to look for others.

### Connect Claude Code

cfo.ai also runs its own MCP server at `https://api.cfo.ai/mcp`, separate from the Connections above. Connect Claude Code to it once, and Ari's tools become available directly inside your terminal sessions.

<Steps>
  <Step title="Add the MCP server">
    Open a terminal and add cfo.ai as an MCP server:

    ```bash
    claude mcp add --transport http cfoai https://api.cfo.ai/mcp
    ```
  </Step>
  <Step title="Start Claude Code">
    ```bash
    claude
    ```
  </Step>
  <Step title="Open the MCP menu">
    Type `/mcp` and look for `cfoai` in the list of servers.
  </Step>
  <Step title="Authenticate">
    Select `cfoai`, then choose **Authenticate**. A browser window opens — make sure you're logged into your production cfo.ai account before approving the connection.
  </Step>
</Steps>

Once authenticated, Claude Code can call cfo.ai's tools for the rest of your session.

## About Fivetran

Most connectors other than CSV upload, QuickBooks Online, and Xero run through **Fivetran**, which handles the underlying sync. You connect the source once, and Fivetran keeps it up to date on a regular schedule.
