---
title: "Work with dates"
description: "Use Date grains, relative period offsets, date functions, ranges, and formula ranges in a cfo.ai calculation."
---

Date references let formulas move through time, group dates, and calculate period boundaries.

## Use the table's granularity

Write Date with the grain used by the formula:

```text
Date.Month
Date.Quarter
Date.Year
```

Supported grains are Day, Week, Month, Quarter, Half, and Year.

## Reference a nearby period

The compact lookup uses the formula's current Date grain:

```text
Revenue[-1]
```

At monthly grain, this reads Revenue from the previous month. A positive value moves forward.

For an explicit date shift, use `dateadd`:

```text
dateadd(Date.Month, -1, "month")
```

Supported units are day, week, month, quarter, half, and year.

## Select a fixed period

```text
Revenue[Date.Month = "2026-01"]
Revenue[Date.Quarter = "2026-Q1"]
Revenue[Date.Year = "2026"]
```

## Look up a timestamp by date

A Dimension filled from a source can hold timestamps rather than plain dates, such as one member per sync at `2026-07-01 00:00:00+00`. A lookup key written as a date, whether `date(2026, 7, 1)` or a date Variable, selects the member at midnight of that day when every member of the Dimension comes from its source rows:

```text
amount_usd$[synced_month = `Snapshot Month`$]
```

The same date in a rule's condition, `[synced_month = date(2026, 7, 1)]`, never matches a timestamp member. Date text such as `"2026-07-01"` reaches the member at that instant in both places. See [A date lookup returns no value](/formulas/formula-reference/formula-errors-and-troubleshooting#a-date-lookup-returns-no-value).

## Test for a missing date

A date Variable nobody entered reads an empty value, not 0, so `` `End Date` = null `` is true where no end date exists. See [Test for an empty value](/formulas/formula-guides/use-conditional-logic#test-for-an-empty-value).

## Select a time window

Use an inclusive range when a calculation spans several periods:

```text
sum(Revenue[Date.Month in "2026-01":"2026-12"])
```

Relative endpoints move with the current period:

```text
sum(Revenue[Date.Month in [-12]:[-1]])
```

## Find a period boundary

```text
startofmonth(Date.Month)
startofquarter(Date.Month)
```

`startofday`, `startofweek`, `startofhalf`, and `startofyear` are also available. See [Date-truncation functions](/formulas/formula-reference/function-reference/date-truncation-functions).

## Read part of a date

```text
year(Date.Month)
month(Date.Month)
quarter(Date.Month)
half(Date.Month)
```

Week functions include `weekday`, `weeknum`, and `isoweeknum`. See [Date-part functions](/formulas/formula-reference/function-reference/date-part-functions).

## Calculate a period end or date difference

```text
eomonth(Date.Month, 0)
datedif(`Start Date`, Date.Month, "M")
```

## Build a date

```text
date(year(Date.Month), 12, 31)
```

## Formula ranges

Actuals and Forecast are formula ranges. **Last close** is the boundary between them: Actuals covers the closed periods and Forecast the later ones, so a Variable can carry one rule for Actuals and another for Forecast.
