---
title: "Date and time functions"
description: "Shift dates, calculate differences, count days in a period, construct dates, and find month-end dates."
---

These functions build dates, shift them, compare them, or return information about a period.

## dateadd

Shifts a date by a signed amount.

```text
dateadd(Date.Month, -1, "month")
```

Supported units are `"day"`, `"week"`, `"month"`, `"quarter"`, `"half"`, and `"year"`. The amount is a signed whole number. The unit must be quoted and lowercase; `"Month"` is not accepted.

## datedif

Returns the difference between a start date and end date using an Excel-style unit code.

```text
datedif(`Start Date`, Date.Month, "M")
```

The supported codes are `Y`, `M`, `D`, `MD`, `YM`, and `YD`, in either case. The start date must not be after the end date. Like Excel, the day units `D`, `MD`, and `YD` count the days between the dates and exclude the end day, so add 1 when you need an inclusive day count.

## daysin

Returns the number of days in the aligned period containing a date.

```text
daysin(Date.Month, "month")
```

Supported units are `"day"`, `"week"`, `"month"`, `"quarter"`, `"half"`, and `"year"`, quoted and lowercase as in `dateadd`. `"day"` always returns 1 and `"week"` always returns 7; `"year"` returns 365 or 366.

## date

Builds a date from year, month, and day numbers.

```text
date(2026, 12, 31)
date(year(Date.Month), 12, 31)
```

Month and day values roll into adjacent months and years, following Excel `DATE` behavior. A year from 0 to 1899 has 1900 added, as in Excel. A result outside years 1 to 9999 returns a `#NUM!` error. The real calendar is used, so February 29, 1900 does not exist.

## edate

Shifts a date by whole months and clamps the day to the target month when needed.

```text
edate(Date.Month, 3)
```

## eomonth

Returns the last day of a month a signed number of months from a date.

```text
eomonth(Date.Month, 0)
```

Use `0` for the current month, `1` for the next month, and `-1` for the previous month.
