Every change to the Model is recorded in version history, whether you made it or Ari did, so you can take any of them back. Choose the method by whose change it is and how far back you want to go.

| You want to | Do this |
| --- | --- |
| Take back an edit you just made | Press **⌘ Z** (**Ctrl Z** on Windows and Linux) |
| Take back a change Ari made | Ask Ari, or undo the entry in version history |
| Take back one older change and keep everything after it | Undo that entry in version history |
| Return the whole Scenario to how it was at a point in time | Restore that version |

## Undo your own last edit

Press **⌘ Z** (**Ctrl Z** on Windows and Linux) to take back the last change you made to the Model, and **⌘ Shift Z** (**Ctrl Shift Z** or **Ctrl Y** on Windows and Linux) to redo it.

**⌘ Z** undoes only the edits you made in this browser tab since it opened. It does not undo Ari's changes or changes from an earlier visit; use version history for those. It does not undo Model changes while you are typing in a text field or the formula editor, or while you are viewing a past version; inside a Page's text, it undoes your typing instead. The notices undo and redo show are listed in [Keyboard shortcuts](/reference/keyboard-shortcuts#undo-and-redo).

## Ask Ari to undo

> Undo that last change.

Ari undoes the most recent change as a whole. You can also describe an older change, such as "Undo the change to the hiring plan from this morning." Ari reads the history and undoes the change you meant.

## Undo one change in version history

<Steps>
  <Step title="Open version history">
    Select **Version history**, the clock icon in the Page header. Entries are listed newest first, each with who made the change, when, and what it touched.
  </Step>
  <Step title="Find the change">
    Use **Filter version history** to show only some people or kinds of change, or **Jump to date** to move to a day.
  </Step>
  <Step title="Undo it">
    Point at the entry, select its **…** actions button, and choose **Undo this change**. Undo puts back only what that change wrote, such as a Page's name or one formula, and keeps every later change. If a later change edited the same thing, nothing is undone, and a notice names that later change: **A later change edited the [field] of [subject], so this change can’t be undone on its own.** Undo the later change first, then this one. In a Scenario, undoing its only edit to something it read from Main returns that item to Main's current version; see [Version history records every change](/concepts/scenarios#version-history-records-every-change). A change a Scenario inherited from Main, whose summary reads **in Main Scenario**, has no **Undo this change** inside the Scenario; undo it in Main.
  </Step>
</Steps>

The undone entry is struck through and marked **Undone**, and the new entry that records the undo offers **Redo this change**.

## Restore an earlier version

Restoring returns the whole Scenario to an earlier point and rolls back every change made after it.

1. In version history, select the entry for the point you want. The Model shows how it looked then, with a banner that reads **Viewing [time] · Read only**.
2. Select **Restore** in the banner, or open the entry's **…** actions button and choose **Restore this version**.
3. Review the dialog, which names the changes it will undo and who made them, and select **Restore version**.

The restore is itself a recorded change, so you can undo it. Restoring needs full access to the Scenario, and neither undo nor restore is offered on a Snapshot, which is pinned to one moment. In a Scenario other than Main, changes made in Main stay as they are. When Scenarios were branched from this one, the dialog offers to restore them to the same time as well.

To leave the past version without restoring it, select **Back to latest**.
