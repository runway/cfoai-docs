To export a Page to Excel, select **Download spreadsheet** in the Page header and choose **With formulas**, or ask Ari to export it. You get an Excel workbook (`.xlsx`) with one sheet for each table on the Page, and its numbers are live Excel formulas, not pasted values. When you want the numbers without the formulas, or a large Model takes too long to export, [export values only](#export-values-only). A Page whose figures are drawn by Canvas blocks exports too: each dataset a Canvas block draws becomes a sheet of values. To put several Pages in one workbook, such as your three financial statements, ask Ari.

## Are the formulas live?

Yes, in a **With formulas** export, which is also what Ari exports unless you ask for values only. Each number a formula calculates in cfo.ai is an Excel formula in the workbook. The numbers those formulas read from outside the Page, such as typed assumptions and imported Actuals on other tables, sit on a **Model inputs** sheet. Change an input in Excel and every cell that depends on it recalculates. A formula that chooses among several inputs with `first` or `last`, such as `` first(`Preferred start`, `Fallback start`) ``, stays live too: Excel chooses again when you change an input.

The workbook is a copy. Changes you make in Excel do not flow back into cfo.ai.

Formulas and the **Model inputs** sheet need access to every Variable and Dimension in the Scenario. Someone without it, such as a person who opens the Page through a share link, gets the numbers the Page shows as plain values, with no **Model inputs** sheet, whichever format they choose. That workbook is the same as a [values-only export](#export-values-only), and its **Export notes** sheet says that it holds values.

A few formulas cannot be written as Excel formulas, such as one longer than Excel allows. Those cells keep their calculated value instead of a formula, and an **Export notes** sheet lists each one. A formula that names items of a numeric Dimension as text, such as deal IDs, finds their cells by number, and a formula that names an item the workbook has no cell for keeps its calculated value and is listed in **Export notes** rather than being written without that item. A cell that reads text or dates, such as a cost center or an end date, from several periods or Dimension items also keeps its calculated value and is listed, because an Excel formula cannot preserve text or dates read from several cells; a text or date read that matches one cell stays a reference to that cell. The download notice counts them and offers **Ask Ari to fix**, which asks Ari to export the Page again and write a working formula into each of those cells.

## Export values only

To export a Page's numbers without its formulas, select **Download spreadsheet** and choose **Values only**, or ask Ari to export the Page as values only. Use it when you want fixed numbers to send, or when a **With formulas** export of a large Model fails or takes too long.

A values-only workbook has the same sheets for the Page's tables and Canvas data, with these differences:

- Each cell a Model formula calculates holds the calculated value, not an Excel formula, so the numbers do not update when you change an input in Excel.
- Subtotal and comparison columns stay Excel formulas, because they read only cells the sheet shows, and recalculate from those values.
- There is no **Model inputs** sheet.
- An **Export notes** sheet says that the workbook holds values; [The cfo.ai interface](/reference/interface#download-spreadsheet) has its wording.

A values-only export does not calculate the inputs that formulas read from outside the Page, which a **With formulas** export needs for the **Model inputs** sheet, so it does less work on a large Model. It still calculates the Page's own tables.

When a **With formulas** export fails, its **Could not download spreadsheet** notice offers **Download values only**, which starts a values-only export of the same Page. cfo.ai does not make that switch for you.

## When an export runs out of time

An export calculates the selected Pages one at a time, each Page's tables and then the inputs those tables read, and stops calculating before its time limit so that it has time to write the workbook; the limit and the time kept for writing are in [Limits and file types](/reference/limits#tables-pages-sharing-and-exports). An export that reaches its allowance of calculated cells or calculation requests, listed there too, stops the same way. The workbook then holds every Page whose tables finished, and its **Export notes** sheet names the Pages left out. On a Page that is in the workbook, a cell that reads an input the export did not reach keeps its calculated value and is listed in **Export notes**. When the first Page with a table did not finish, there is nothing to write, and the export fails at whichever limit it reached, time or calculation allowance; a new export of the same Pages reaches the same limit while the Model is unchanged, so export fewer Pages or narrow the tables. An export of one Page, such as one from the **Download spreadsheet** button, never leaves a Page out: it finishes or fails. Ari's export reports the Pages left out too, and the table that was still calculating when time ran out.

An input the calculation engine stops at its time or memory limit is handled the same way: the export asks for a large group of items once more in halves, and when the engine still stops it, the cells that read it keep their calculated values and are listed in **Export notes**. When the Page's tables and their inputs together pass the workbook's size limit, the export writes the workbook once more without the **Model inputs** sheet: the tables keep the formulas that refer to each other, and a cell that reads an input keeps its calculated value and is listed.

A table whose formulas cannot be worked out within the time limit for one table calculation is written as values instead of failing the export. **Export notes** names each such table at the top, and the table's own sheet carries a subtitle that says its numbers are fixed; subtotal and comparison columns on it still recalculate from those numbers, the other tables keep their formulas, and Ari is told which tables were written as values. The messages are listed in [The cfo.ai interface](/reference/interface#download-spreadsheet).

An input too large to read is left out, and the cells that read it keep their calculated values; **Export notes** says the workbook may hold only some cells of that Variable. A total over such an input, such as a sum across every region, also keeps its calculated value, so no formula in the workbook adds up only part of the data. A Page's own table that large fails the export. A workbook that has no room left to name the Pages it leaves out fails instead of looking complete. The sizes are in [Limits and file types](/reference/limits#tables-pages-sharing-and-exports).

## What you get

- One worksheet for each table on the Page, in the Scenario you exported. A table's Scenario comparison columns come along, and rows and columns hidden on the table are left out.
- One worksheet for each dataset a Canvas block on the Page draws, after the table sheets. It holds the whole dataset, including rows the block reads but does not draw, as plain values with no formulas; no formula reads these sheets, and they add nothing to the **Model inputs** sheet. The sheet is named for the block's title, with the dataset's name added as **[title] · [dataset]** when the block draws more than one dataset. When that name is longer than the 31 characters Excel allows, the title is shortened, or left out when the dataset's name leaves it no room, and the dataset's name is kept. A dataset name that is itself longer than 31 characters is cut at its end to fit. A dataset saved for another Scenario names that Scenario under the sheet title, and its Variable column headings use the names that Scenario gives the Variables. You get the datasets the Page shows you: a dataset in a Scenario you cannot open is left out, and so is one whose saved query the Model refuses to calculate.
- Text blocks and charts are left out.
- A table with **Subtotals below details** keeps that layout: each expanded group becomes a heading row with its name and no values, then its detail rows, then a row labeled **Total [name]** that holds the group's formulas; a name that already starts with "Total" keeps its name. See [Put subtotals below their details](/guides/format-a-table#put-subtotals-below-their-details).
- A date cell stays a real Excel date, shown in the day form of the **Date format** chosen on the table: **Abbreviated** as `Sep-30-26`, **ISO standard** as `2026-09-30`, **Full month** as `September 30, 2026`, **Compressed year** as `Sep 30 ’26`, **Year-first slash** as `2026/09/30`, **Month-first slash** as `09/30/2026`, **Period-separated** as `2026.09.30`, **Day-first formal** as `30-Sep-2026`, and **Descriptive** as `30-Sep-26`. A table that never had a **Date format** chosen shows **Abbreviated** on the Page but exports its date cells as `2026-09-30`. The formats are listed in [Date formats](/reference/table-blocks#date-formats).
- Each number keeps its format: currency, percentage, or a multiple such as `3.5x`, with up to five decimal places. A table shown in thousands, millions, or billions keeps that **Scale** in the workbook, with the suffix `K`, `M`, or `B`; percentages and multiples are never scaled. A negative number shows as the Page shows it: with a minus sign, or in parentheses where the table or the workspace chose **Negatives** → **Parentheses** (see [Format and arrange a table](/guides/format-a-table#show-negative-numbers-in-parentheses)). Excel picks the parentheses by the exact value, so a negative that rounds to zero exports as `(0.00)` where the Page shows `0.00`.
- A blank input stays blank rather than becoming 0, and an input that holds text, such as a customer name, stays text. A function of a blank, such as `round`, `abs`, or `year` of an empty cell, is written so that Excel also shows blank after it recalculates, instead of 0 or 1900, and an average or median skips those blanks as cfo.ai does.
- In a workspace with a brand, the filled row at the top of each worksheet that holds the table's title in white takes the brand's text color as its fill, and the first three Dimension colors take the brand's chart colors when it has them. See [Brand your workspace](/guides/brand-your-workspace).

## Other formats

- For Google Sheets, upload the workbook to Google Drive and open it with Google Sheets.
- For a CSV file, ask Ari for a CSV of a table, and it gives you the file in the chat. There is no CSV button.
- For a PDF, see [Get a PDF report or slide deck](/guides/get-a-pdf-or-slides).

## If something goes wrong

A failed export shows **Could not download spreadsheet** with the Page's name and the reason. When a **With formulas** export ran and then failed, the message also offers **Download values only**; see [Export values only](#export-values-only). An export that was cancelled, or refused before it started, does not offer it. When the reason names a table and Excel's worksheet limits, the table's saved layout is too large for one worksheet; narrow the table, or hide rows or columns, before exporting again. Every progress label and message is listed in [The cfo.ai interface](/reference/interface#download-spreadsheet). For export time and size limits, see [Limits and file types](/reference/limits#tables-pages-sharing-and-exports).
