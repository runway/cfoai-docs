Use this when Ari is working and you want to change course, add a detail you forgot, or stop it. You do not have to wait for Ari to finish before you say more.

| You want to | Do this |
| --- | --- |
| Change direction now | Type the correction and press **Enter** |
| Add something for after Ari finishes | Type it and press **⌥ Enter** (**Alt Enter** on Windows and Linux) |
| Stop Ari | Select **Stop**, or press **Esc** in the message box |
| Ask about one part of an answer | Select the words and choose **Reply** |
| Pick up a reply that stopped | Select **Retry** |

## Steer Ari while it works

Type your message and press **Enter**. The message reaches Ari at its next step, and Ari adjusts what it is doing. Until Ari takes it, the message waits above the message box with the caption **Sending to the current turn**.

> Do this in a Downside Scenario and leave Main unchanged.

> Use our QuickBooks numbers for March, not the estimate.

You can attach a file while Ari works too, such as a screenshot you paste into the message box, and send it with or without text.

Your message can be about something else, such as a view that is not working while Ari builds a forecast. Ari then finishes the step it is on and answers your message, and it knows which request it was working on when your message cut it short. That request stays part of what you asked until it is done, until you press **Stop**, or until a later message changes or replaces it, so Ari can return to it or tell you it is still unfinished. Say "never mind the forecast" when you want it dropped.

## Queue a message for after Ari finishes

Type your message and press **⌥ Enter**. It waits with the caption **Queued for after this turn**, and Ari reads it when it finishes what it is doing. To send a queued message to the current turn after all, select **Steer now** on it.

## Edit or delete a waiting message

Point at a waiting message:

- Select the edit button (**Edit pending message**) to take it back into the message box, change it, and send it again.
- Select the delete button (**Delete pending message**) to remove it before Ari reads it.

A message with files, a quoted excerpt, a plan approval, or answers to Ari's questions can only be deleted, not edited. A message that has already started a turn cannot be edited or deleted. See [Chat controls and messages](/reference/chat#messages-you-send-while-ari-works) for the notices.

## Stop Ari

Select **Stop**, which replaces **Send** while Ari works and the message box is empty, or press **Esc** in the message box. The chat shows **Conversation interrupted - tell Ari what to do differently.** Then say what you want instead.

Changes Ari saved before you stopped it stay in the Model. To see what it finished, look at the Page or ask "What did you change before I stopped you?" To take those changes back, see [Undo a change or restore an earlier version](/guides/undo-changes).

Stop cancels the request Ari was working on. Ari knows in its next turn that you pressed **Stop**, so it does not pick the request back up on its own; ask again if you want it finished.

## Reply to one part of an answer

Select the words in Ari's answer that you want to ask about. Choose **Reply** above the selection, or press **⌘ L**, and the passage lands in the message box as a quote. Type your question and send it. You can quote up to five passages in one message. See [Chat controls and messages](/reference/chat#reply-to-part-of-an-answer).

## Recover a reply that stopped

If the chat says **Ari stopped before finishing.**, select **Retry** to have Ari pick the work back up; anything it saved before it stopped is still in the Model. For **Not sent.**, a chat that grew too long, and other errors, see [Ari stopped or showed an error](/guides/ari-is-slow-stuck-or-wrong#ari-stopped-or-showed-an-error).
