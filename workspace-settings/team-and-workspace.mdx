Your workspace has a few settings that apply model-wide, rather than to any single Variable or Table Block. Ask Ari to change most of these directly.

## Rename the workspace

Ask Ari to rename your workspace. Renaming regenerates the workspace's URL slug, so any link built from the old slug changes along with it.

## Time defaults

Ask Ari to set the model's default time settings:

- **Granularity** — the default roll-up grain for new tables, usually month.
- **Range** — the default start and end date a new table shows.

These are defaults for new Table Blocks; an existing table's own window isn't affected until you change it directly.

## Last close

**Last close** is the date your Model computes Actuals against — everything at or before it is Actuals, and everything after is Forecast. Ask Ari to set it after each period closes in your books. Several other workflows, like building a Headcount page, depend on Last close being set correctly first.

## Team directory and groups

Ask Ari to look up who's in the workspace: members, their roles, and any pending invites, filtered by name or email if you're looking for someone specific. Ari can also list user groups and who belongs to each, which is useful when you're about to share a Page or Scenario and want to confirm who a group actually reaches.

Inviting new members, changing roles, and creating or editing groups happens from Settings in the app itself.
