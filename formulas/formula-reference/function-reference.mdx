Functions perform common calculations inside formulas. The reference is grouped by purpose.

<Warning>
  Not every function on these pages is available in cfo.ai yet. Functions marked **🚧 Not yet available** are designed and planned, but do not currently compute — using one in a formula will fail. Functions without that marker are live today.
</Warning>

## Available now

- **Conditional:** `if`
- **Aggregation:** `sum`, `avg`, `min`, `max`, `count`, `first`, `last`
- **Math:** `abs`, `sqrt`
- **Date truncation:** `startofday`, `startofweek`, `startofmonth`, `startofquarter`, `startofhalf`, `startofyear`
- **Date offset:** `offset`

## Function groups

- Aggregation functions combine several values
- Math functions transform numbers
- Conditional functions choose a result
- Date-part functions read part of a date
- Date-truncation functions return the start of a period
- Date and time functions build, compare, or shift dates

Use lowercase function names. Function names are not case-sensitive, but lowercase matches the editor's preferred authoring style.

The internal `any` aggregate is not part of the public function catalog. Use the `ANY` dimension selector only inside a segment lookup.
