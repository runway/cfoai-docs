---
title: "Ask Ari to explain existing formulas"
description: "Ask Ari to inspect a Variable's saved formulas, explain where each rule applies, and trace the values in a Table Block."
---

Ari can find the formulas attached to a Variable and explain how they work together.

## Start with the Variable

> How is Gross Margin calculated?

Ari resolves the Variable and reads its formulas in the current Scenario.

## Ask about scope

> Show me the formulas used for Payroll, including formulas that apply only by Department.

> Why does Payroll use a different formula for Sales?

> Which formula applies to Payroll in Forecast?

A Variable may have a default formula, Dimension-specific formulas, segment-specific formulas, and formula-range rules. Ask Ari to compare their scopes when the result changes across the Model.

## Point Ari to the model

When possible, open the page or table you are asking about. You can also reference a Variable, row, cell, or table directly in your message.

Examples:

> Explain the formula for this row.

> Why is this value different in the Sales column?

> Compare the formulas behind this Actuals value and this Forecast value.

## Ask for business language

> Explain this formula in plain language and tell me where it applies.

A useful explanation should cover:

- What the expression calculates
- Which Variables it references
- Where it applies
- Whether a more specific formula can override it
- Which formula range and Scenario it belongs to.

Reading formulas does not change the Model.
