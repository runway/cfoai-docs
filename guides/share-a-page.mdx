Use a share link when someone outside your workspace needs to read a report, such as a board update or a cash forecast. The link opens the Page read-only, without a sign-in or a cfo.ai account, in the Scenarios you choose. One link can open different Pages in several Scenarios, such as the Board summary in Main and the Revenue model in a Downside Scenario. Everyone inside your workspace can already open every Page, so you do not need a link for teammates.

<Tabs>
  <Tab title="Ask Ari">
    Ask Ari for a view-only link and name the Page:

    > Create a view-only link to the Board summary Page.

    Ari returns the link's address. To have one link open several Pages, name them all. The Page you name first is where the link lands, and every Page opens in the Scenario you name, or in your chat's Scenario when you name none:

    > Create a view-only link to the Board summary Page that also opens the Cash forecast and Headcount plan Pages.

    To have one link open Pages in several Scenarios, say which Scenario each Page belongs to:

    > Create a view-only link to the Board summary Page in Main that also opens the Revenue model Page in the Downside Scenario.

    To label the link for the people in your workspace, give Ari a name for it:

    > Create a view-only link to the Board summary Page and name it "Board – Q4 investors".

    Creating a link does not change the Model. Later, Ari can change the Pages the link opens, move it to another Scenario, give it a memorable address, or turn it off; see [Ask Ari to change a link or turn it off](#ask-ari-to-change-a-link-or-turn-it-off). Ari cannot rename a link, add or change a password, or edit the link's preview; do those in the **Share** panel.
  </Tab>
  <Tab title="By hand">
    <Steps>
      <Step title="Open the Page readers should land on">
        Open the Page in the Scenario readers should see first: pick the Scenario in the sidebar's Scenario picker, then select the Page from its list. The link opens on this Page, in this Scenario.
      </Step>
      <Step title="Open the Share panel">
        Select **Share** in the Page header. The panel's title names the Page, so you can confirm you are sharing the right one. It opens on its **Share** tab, which holds the links; the **Export** tab beside it [exports the Page to Excel](/guides/download-a-spreadsheet).
      </Step>
      <Step title="Start a new link">
        Under **External access**, select **Create link**. The panel changes to **New link**, which lists the Pages you can share in this Scenario. The Page you started from is ticked and marked **Opens here**; readers land on it.
      </Step>
      <Step title="Name the link, if you want">
        In **Name**, type a label that says who the link is for, such as "Board – Q4 investors". Only people in your workspace see the name; readers never do.
      </Step>
      <Step title="Add more Pages, if you want them">
        Tick each other Page the link should open, or **Select all**. **Find a page** narrows a long list.
      </Step>
      <Step title="Add more Scenarios, if you want them">
        Select **Add scenario**, tick the Scenarios or Snapshots to add, and select the button that counts them, such as **Add 2 scenarios**. Each added Scenario starts with the Pages you ticked in the first one, where they exist in it. To change a Scenario's Pages, select it in the **Scenarios** list. To tick a Page in every Scenario that has it, select **All scenarios**. A Scenario with no Page ticked is left out of the link. One link opens up to 50 Pages, and a Page counts once for each Scenario it opens in.
      </Step>
      <Step title="Create the link">
        Select **Create link**. The panel returns to the Page's links, and the new link appears with its **Link settings** open.
      </Step>
      <Step title="Add a password, if you want">
        In **Link settings**, turn on **Require password**. Turning on the password fills in a generated password; type your own instead if you prefer. Select **Save changes**. Saving gives the link a new address, so copy it after you save.
      </Step>
      <Step title="Copy the link">
        Select the copy button on the link (**Copy external link**) and send it to the reader. Send a password separately from the link.
      </Step>
    </Steps>
  </Tab>
</Tabs>

The link works for anyone who has it until you turn it off, and cfo.ai does not list it publicly. It never lets an outside reader edit anything; a teammate who opens it keeps the access they already have. To see exactly what a reader can and cannot see, read [Sharing and access](/concepts/sharing-and-access).

## Change a link's Scenario or password

1. Open the Page and select **Share**.
2. On the link, open **Link settings**.
3. Change **Shared scenario**, turn **Require password** on or off, or select **Generate password** for a new one. **Show password** displays the current password. You can change **Shared scenario** only on a link whose Pages are all in one Scenario. A link that opens Pages in several Scenarios does not show it, and an old link that opens a Page in every Scenario shows it as **All scenarios**, with nothing to pick.
4. Select **Save changes**.

Saving replaces the link: the old address stops working, people who opened the Page through it lose that access, and the new address is shown in its place. Send the new address to everyone who should keep reading.

To see what a link opens, select **Details** on it.

## Name a link so you can tell links apart

Give a link a name, such as "Board – Q4 investors", when a Page has several links and you need to know which one went to whom. The name is a label for people in your workspace. Readers never see it, and naming or renaming a link keeps its address, Pages, and password.

1. Open the Page and select **Share**.
2. On the link, select **Name this link** (the pencil icon). On a link that already has a name, the button reads **Rename link**.
3. Type the name and press **Enter**, or click outside the field. **Esc** keeps the old name. To remove a name, clear the field and press **Enter**.

The name becomes the link's title in the **Share** panel, with the address under it, and the question you confirm when you turn the link off names it. You can also rename a link from **Details**. Once a Page has more than five links, **Find a link** searches them by name, address, memorable address, or the person who made them. The length limit, who can rename a link, and each message are in [The cfo.ai interface](/reference/interface#share-panel).

## Change the Pages a link opens

You can add or remove a link's Pages and Scenarios without changing its address or password, so people who saved the link keep one address. **Edit pages** is not offered on an old link that opens a Page in every Scenario, or on a link whose first Page is in a Scenario that was deleted. For those, create a new link, then turn off the old one.

1. Open one of the link's Pages and select **Share**.
2. On the link, select **Details**, then **Edit pages**.
3. Tick or untick Pages, and add or remove Scenarios, as you did when you created the link. The Page the link opens first stays ticked.
4. Select **Save**. It stays off until the ticked Pages differ from the Pages the link opens.

A Page you remove stops opening at once for everyone who opened the link. A Page you add opens the next time a reader opens the link's address. You cannot change the Page a link opens first; create a new link for that, then turn off the old one. You can also [ask Ari](#ask-ari-to-change-a-link-or-turn-it-off) to add or remove a link's Pages.

## Give the link a memorable address and a preview

A link without a password gets a short public address and a preview card. The card is the picture, headline, and description that chat and social apps show when someone pastes the link. cfo.ai writes the first preview from the Page. The card names cfo.ai unless an administrator turns on **Show the brand on link previews** in **Settings → General → Brand**; see [Brand your workspace](/guides/brand-your-workspace#who-sees-the-brand).

1. On the link, select **Edit share preview**.
2. Edit the card's **Headline** and **Description**. For a different picture, select **Create new artwork** and choose one of the three options it makes.
3. Select **Publish changes**.
4. To give the link a readable address, type it under **Memorable address**, such as `board-update`, and select **Update**. **Copy link** copies the address.

A memorable address can be guessed, so use a password-free link only for Pages you are happy for anyone with the address to read. Changing the address retires the old one. A link that needs a password has no memorable address or preview to edit; its password prompt shows your brand when **Show the brand on link previews** is on.

## See every link your workspace has shared

The **Share** panel lists the links of one Page. To see what the whole workspace has shared, ask Ari:

> What have we shared outside the workspace?

Ari lists the share links that are on and give access, newest first, across every Scenario. An administrator's list holds every such link. For anyone else, the list holds the links they made and the links that open only Pages they have full access to. For each link it can tell you the link's name, when it has one; its address, and its memorable address when it has one; the Page readers land on and the other Pages the link opens, with the Scenario of each; when the link was created and, when a name is recorded, who created it; whether it needs a password; how many accounts still hold access they got through it; and how often the link was opened. The access number counts accounts, including readers who never signed in. It does not count visits or people; for those, see [See how often a link was opened](#see-how-often-a-link-was-opened). A Page that was deleted, or that you cannot read, is counted but not named.

Ari reads up to 100 links at a time, so in a workspace with more, ask it for the rest. Links that are turned off are left out. The list holds each link's address, so to find out which link an address belongs to, paste the address or the memorable address into the chat and ask Ari. Ari can match it only to a link that is still on. For a link whose first Page you can open, Ari can also give you an address that opens that Page with the **Share** panel already open. That works in a desktop browser; on a phone or tablet the address opens the Page alone, because that layout has no **Share**.

You can also ask Ari which Pages people outside the workspace can open; it answers for one Scenario at a time and names only Pages you have full access to.

## See how often a link was opened

To find out whether an investor or a board member opened a link, ask Ari:

> How many times has the "Board – Q4 investors" link been opened?

> Who opened the board link, and when?

Ari answers for a link that is still on and that the list above shows you. It can tell you:

- How many times the link was opened. Every open counts, including a second open by the same person and an open by a teammate who already has access.
- How many accounts opened it. The number can be higher than the number of people: a reader who is not signed in counts again in another browser, or after their access in a browser has ended.
- When the link was last opened.
- Each open, newest first, with its time. An open by someone signed in to cfo.ai shows that person's name. An open by a reader who was not signed in shows no name, even if that reader signs in later.

cfo.ai counts an open when someone opens the link's address and gets in. A wrong password adds nothing, and neither does moving on to the link's other Pages. Opens are counted from the time cfo.ai began recording them, and earlier opens are not listed, so a count of zero on an older link does not mean nobody read it. Ari can tell you when recording began. Once a link is turned off, Ari no longer reports its opens.

## Ask Ari to change a link or turn it off

Ari can turn a link off, change the Pages it opens, move it to another Scenario, or set its memorable address. Say which link you mean by its name, by the Pages it opens, or by when it was made. For a link whose maker cfo.ai recorded, you can also say who made it:

> Turn off the "Board – Q4 investors" link.

> Add the Headcount plan Page to the "Board – Q4 investors" link and take the Cash forecast Page off it.

Ari finds the link in the list described above, so it can change only a link that is still on and that the list shows you. You can also paste the link's address or its memorable address, and Ari matches it against that list.

| You ask Ari to | What happens |
| --- | --- |
| Turn a link off | The address stops opening anything, and everyone who opened the Pages through the link loses that access, as with **Also remove access already granted by this link** in the **Share** panel. To let them keep their access, tell Ari to keep it. A link that is off cannot be turned back on; create a new link instead. |
| Add or remove Pages | The link keeps its address, its password, and the Page it opens first. A Page you remove stops opening at once for everyone who opened the link. A Page you add opens the next time a reader opens the link's address, and it can be in another Scenario. Ari cannot change the Page a link opens first, or the Pages of an old link that opens a Page in every Scenario. For a link whose first Page is in a Scenario that was deleted, create a new link instead, as you would by hand. |
| Move the link to another Scenario | Ari replaces the link with a new one that opens the same Pages in the new Scenario, under the same name. The old address stops working, people who opened the Pages through it lose that access, and Ari gives you the new address to send. This works for a link without a password whose Pages are all in one Scenario, when every Page exists in the new Scenario. A memorable address does not move to the new link; ask Ari to set it again. |
| Set, change, or remove a memorable address | Works for a link without a password. Changing the address retires the old one, and Ari gives you the new address. The rules for an address are in [The cfo.ai interface](/reference/interface#share-preview). |

Turning a link off works for the person who made it and for anyone with full access to every Page it opens. Changing a link also needs full access to every Page it opens after the change and, for anyone but the person who made the link, to every Page the change removes. Ari cannot rename a link, add, change, or remove its password, or edit its preview; do those in the **Share** panel.

## Turn a link off

Turn a link off in the **Share** panel, as below, or [ask Ari](#ask-ari-to-change-a-link-or-turn-it-off).

1. Open the Page and select **Share**.
2. On the link, select **Turn off external link** (the trash icon).
3. **Also remove access already granted by this link** starts checked, so everyone who opened the Page through the link loses access too. To let them keep their access, clear it.
4. Select **Turn off link**.

Every label and message in the **Share** panel and its **New link** view, and what a reader sees when a link is off, needs a password, or opens several Scenarios, is listed in [The cfo.ai interface](/reference/interface#share-panel).

## Invite one person by email to view a Page

Use an invitation when a Page should open only for a named person who signs in, such as your accountant, and a link that anyone could forward is too open. You do this by asking Ari in a chat in cfo.ai. The **Share** panel has no field for inviting a person by email, and Ari cannot prepare an invitation from Slack or from an AI tool you connected.

<Steps>
  <Step title="Ask Ari">
    In a chat in cfo.ai, ask Ari to invite the person to view the Page, and give the address:

    > Invite pat@example.com to view the Board summary Page.

    One request can name up to 20 addresses.
  </Step>
  <Step title="Check the card">
    Ari shows a card that names each person, the Page, and the Scenario. Nothing is saved or sent yet.
  </Step>
  <Step title="Select Invite">
    Select **Invite** on the card. cfo.ai saves the invitations and emails each person, and the card says what happened, such as **Invitations sent.**
  </Step>
</Steps>

Each person gets an email with a button that opens the Page. The Page opens only after they sign in with exactly the address you invited, so forwarding the email gives nobody else access. They can view that Page in that Scenario and nothing else, and they see it as a share link's reader does; see [What a link's reader sees](/concepts/sharing-and-access#what-a-links-reader-sees).

An invitation is not a share link. The **Share** button shows no link icon for it, and the **Share** panel does not list the people you invited. **Settings → Workspace** does not list them either. To take the access away, ask Ari to cancel the person's invitation, or, once they have signed in, to remove them from the workspace. The card's labels and messages are in [Page invitation card](/reference/chat#page-invitation-card).
