Use a Page's **Share** control when you want someone else to view a report, dashboard, or analysis. Share links are read-only and can open without requiring the recipient to sign in.

## Create a Page share link

<Steps>
  <Step title="Open the Page">
    Navigate to the Page you want to share and confirm that you have permission
    to manage its access.
  </Step>
  <Step title="Choose Share">
    Open the Page's **Share** control. The sharing panel identifies the Page so
    you can confirm you are sharing the intended report.
  </Step>
  <Step title="Choose the Scenario">
    Use the **Shared scenario** selector on the link to choose the Scenario it
    shows. This matters when the same Page presents different results in Main
    and in an alternative Scenario.
  </Step>
  <Step title="Create the link">
    Under **External access**, select **Create link**. Turn on **Require password**
    when the recipient should enter a password before viewing the Page, and copy
    and share that password separately from the link.
  </Step>
  <Step title="Copy the link">
    Select **Copy external link** and send it to the intended recipient.
  </Step>
</Steps>

## Share several Pages through one link

One external link can open more than one Page in the same Scenario, so a board packet with a summary, a profit and loss statement, and a headcount view opens as one link. The Page you share from is the landing page. Ask Ari for a link like this; the **Share** panel's link rows then list every Page the link opens.

> Create a view-only link to the Board summary Page that also opens the Cash forecast and Headcount plan Pages.

Ari returns the link's address. The link works for anyone who holds it until you revoke it in **Share**, and creating it does not change the Model.

## Know what a link allows

A Page share link grants viewing access. It does not give the recipient permission to edit the Model or become a workspace administrator.

Everyone inside the workspace is an administrator and can already open every Page, so sharing is for people outside it. When someone needs to collaborate directly, ask Ari to invite them as a workspace administrator; see [Workspace and team settings](/workspace-settings/team-and-workspace).

## Manage existing links

The sharing panel lists active links. Remove a link when the recipient should no longer be able to use it, and create a new link if the required Scenario or password changes. Revoking a link is only possible from the panel, not through Ari.
