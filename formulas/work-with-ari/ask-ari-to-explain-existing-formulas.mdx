---
title: "Ask Ari to explain existing formulas"
---

Ari can find the formulas attached to a property and explain how they work together.

## Start with the property

> How is Gross Margin calculated?

Ari resolves the property and reads its formulas in the current scenario.

## Ask about scope

> Show me the formulas used for Payroll, including formulas that apply only by Department.

> Why does Payroll use a different formula for Sales?

> Which formula applies to Payroll in Forecast?

A property may have a default formula, segmentation formulas, segment formulas, and Formula-period formulas. Ask Ari to compare their scopes when the result changes across the model.

## Point Ari to the model

When possible, open the page or table you are asking about. You can also reference a property, row, cell, or table directly in your message.

Examples:

> Explain the formula for this row.

> Why is this value different in the Sales column?

> Compare the formulas behind this Actuals value and this Forecast value.

## Ask for business language

> Explain this formula in plain language and tell me where it applies.

A useful explanation should cover:

- What the expression calculates
- Which properties it references
- Where it applies
- Whether a more specific formula can override it
- Which Formula period and scenario it belongs to

Reading formulas does not change the model.
