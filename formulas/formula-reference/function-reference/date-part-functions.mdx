---
title: "Date-part functions"
description: "Extract a year, month, day, quarter, half-year, weekday, week number, or ISO week number from a date."
---

Date-part functions return a numeric part of a date.

## year

Returns the four-digit year.

```text
year(Date.Month)
```

## month

Returns the month as a number from 1 to 12.

```text
month(Date.Month)
```

## day

Returns the day of the month from 1 to 31.

```text
day(Date.Day)
```

## quarter

Returns the calendar quarter from 1 to 4.

```text
quarter(Date.Month)
```

## half

Returns 1 for January through June and 2 for July through December.

```text
half(Date.Month)
```

## weekday

Returns the day of the week as a number.

```text
weekday(Date.Day)
weekday(Date.Day, 2)
```

Without a return type, Sunday is 1 and Saturday is 7. The optional return type follows Excel: `1` (Sunday = 1), `2` (Monday = 1), `3` (Monday = 0), or `11` through `17` (weeks starting Monday through Sunday, first day = 1).

## weeknum

Returns the week number within the year.

```text
weeknum(Date.Week)
weeknum(Date.Week, 21)
```

Without a return type, weeks start on Sunday and week 1 is the week containing January 1. The optional return type follows Excel: `1` (Sunday), `2` (Monday), `11` through `17` (Monday through Sunday), or `21` for ISO 8601 weeks.

## isoweeknum

Returns the ISO 8601 week number.

```text
isoweeknum(Date.Week)
```

This is equivalent to `weeknum(Date.Week, 21)`.
