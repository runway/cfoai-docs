Use a Scenario when you want to save an alternative plan while keeping Main unchanged. Use a saved Table Block comparison to view the two versions side by side.

## Create a Scenario

Ask Ari to create an editable Scenario from Main:

> Create a Scenario called Hiring Freeze from Main.

You can also start without Ari: select **Main Scenario** in the sidebar, then **Create scenario**.

The Scenario inherits Main and keeps any changes you make separately. Work inside it by updating Variables, changing formulas, adjusting headcount, or reorganizing Pages.

An editable Scenario is created from Main. If you need to preserve another Scenario exactly as it exists now, ask Ari to create a read-only Snapshot instead.

## Compare Scenarios on a Table Block

A Table Block can show one or more Scenarios beside its baseline. Ask Ari to add a comparison, and choose:

- **Which Scenarios** to show alongside the baseline.
- **Layout** — compared Scenarios can sit in columns or in rows.
- **Measures** — the raw value, the delta, the percent difference, or some combination.

A Table Block compares across Scenarios or across a shifted time period, but those two comparison modes cannot be active together. The table can still show ordinary monthly columns while comparing Scenarios.

## Ask Ari about existing Scenario values

If a saved table already contains the relevant information, ask Ari to compare what is visible in each Scenario:

> How does Operating Expense in the Hiring Freeze Scenario compare with Main for next quarter?

If the comparison needs a new saved layout, Ari can add a comparison to a Table Block or create a separate analysis table when you authorize that change.

## Review before merging

Before merging, ask Ari what would change. Review the affected Model content and remember that a successful merge applies those changes to Main and removes the merged Scenario.
