Use this guide to set up the Pages your team reads, such as a Board Page with one subpage per meeting, and to arrange the blocks on each Page. A Page is a document: Text blocks you type in place, with Table blocks and Canvas blocks between them. To learn what Pages and blocks are, read [Pages, Table blocks, and Canvas blocks](/concepts/pages-and-blocks).

You need a desktop browser. A phone browser shows Pages read-only.

## Create a Page

<Tabs>
  <Tab title="Ask Ari">
    Name the Page and, if it belongs inside another Page, name that one too:

    > Create a Page called Board pack inside the Plans Page.

    Ari gives each Page it creates an icon and a color. Ari can also rename a Page, change its icon, move it under another Page or out to the top level, or delete it.
  </Tab>
  <Tab title="By hand">
    <Steps>
      <Step title="Create the Page">
        In the sidebar's **Model** section, select the **+** button, **New page**. cfo.ai creates a Page named **New Page** and opens it.

        To create a Page inside another one, point at that Page in the sidebar and select its **+** button, **New subpage**.
      </Step>
      <Step title="Name it">
        Double-click the Page in the sidebar, or select it and press **F2**, type a name, and press **Enter**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

A workspace with no Pages yet has no **Model** section. Its empty screen reads **Ready to model, [your name]?** Choose **Create with Ari**, or choose **Add block** and a block type to create the first Page with that block on it.

## Rename a Page

Double-click the Page in the sidebar, or select it and press **F2**, type the new name, and press **Enter**. Press **Esc** to cancel. You can also ask Ari to rename it.

A Page does not show its name as a heading above its blocks, and clicking the Page name in the Page header does not rename it. It opens the list of Pages so you can switch to another one.

## Change a Page's icon

Select the icon beside the Page name in the Page header. In the picker, search with **Search icons**, pick a color and a category, select **Shuffle icon** for a random one, or select **Remove page icon**.

## Put Pages in folders by nesting them

cfo.ai has no folders. A Page that holds other Pages works as one: create a Page such as **Board** and put a subpage inside it for each meeting. You can ask Ari to do the moving:

> Move the March, April, and May board Pages inside a new Page called Board.

By hand:

- To nest a Page, drag it onto another Page in the sidebar. Its subpages move with it.
- To reorder Pages, drag a Page between two others. While you drag, move the pointer left or right to choose how deeply the Page nests.
- To use the keyboard, select a Page in the sidebar and press **⌥ ↑** or **⌥ ↓** to move it among its neighbors, **⌥ →** to nest it under the Page above it, or **⌥ ←** to move it out one level. On Windows and Linux, use **Alt**.
- To show or hide a Page's subpages, point at the Page. Its icon turns into an arrow; select it (**Expand subpages** or **Collapse subpages**).

## Keep the Pages Ari creates in order

Ari creates Pages as it builds, so tell it where new work goes before it starts:

> Put any new Pages you create today inside the Q3 forecast Page.

To make that a standing instruction, see [Teach Ari your company's conventions](/guides/teach-ari). Ari can also move the Pages it already created, or delete the ones you no longer need; name them in your request. Ari usually gives a subpage the same icon color as its parent, and Pages on one subject a shared color, so related Pages stand out together in the sidebar.

While Ari is still writing a Page, its sidebar row shows a mark labeled **Ari is building this page**, and the Page header shows **Building…**. The Page cannot be edited until Ari finishes.

## Delete a Page

Point at the Page in the sidebar and select its trash button, **Delete page**.

- The Page and its blocks are deleted. Its subpages move up one level and stay.
- When you are viewing a Scenario other than Main, the Page is deleted in that Scenario only. Main keeps it.
- Most deletes happen without a question. cfo.ai asks first only when the Page holds the last table that shows a Variable or Dimension. See [Delete a table that other content uses](#delete-a-table-that-other-content-uses).

To bring a Page back, press **⌘ Z** (**Ctrl Z**) in the same browser tab, or undo the change in version history. See [Undo a change or restore an earlier version](/guides/undo-changes).

## Add a block to a Page

A block goes where your cursor is. Click an empty line, or press **Enter** at the end of a paragraph to make one.

- Type **/** on an empty line, or point at the left edge of a line and select its **+** button, **Add block**. The block list opens with **Table block** and **Canvas block** first, then the text blocks, such as **Heading 1**, **Bullet List**, and **Toggle List**. Keep typing to narrow the list, and press **Enter** to add the highlighted block. [Writing on a Page](/reference/interface#writing-on-a-page) lists every block.
- A **Simple table** is a small grid of text. It reads no Model values; for numbers, add a **Table block**.

The block list has no chart block. Ask Ari for a chart, and it builds one in a Canvas block; see [Change a chart or Canvas block](/guides/change-a-visual). To build a table, see [Build a Table block by hand](/guides/build-a-table). A workspace with no Pages yet offers **Add block** on its empty screen instead; see [Create a Page](#create-a-page).

## Move, copy, or delete a block

Point at the left edge of a block or a paragraph to show its handle, a grip of six dots, **Open block menu**. Drag the handle up or down to move the block. Click the handle to open the block menu; with a Table block or Canvas block selected, **Shift F10** opens it too.

For a Table block or Canvas block:

- To move the block to another Page, choose **Move to page**, then a Page, or **New page** to move it to a new one.
- To copy the block, choose **Duplicate block**. A copy of a table shows the same Variables, not new ones, so a value you type in either table appears in both. To try different numbers without changing the plan, use a Scenario; see [Test a decision in a Scenario](/guides/test-a-decision-in-a-scenario).
- To delete the block, choose **Delete block**.

For a Text block, such as a paragraph, heading, or list, the menu offers **Mention text in chat** (**Mention table in chat** on a simple table), **Mention in new chat**, **Duplicate block**, and **Delete block**. Text moves only within its Page.

Moving a block, on its Page or to another Page, keeps all its settings. Deleting a block and building it again does not.

There is no command to copy a whole Page. Duplicate its blocks and move them to a new Page.

### Delete a table that other content uses

No table owns a Variable or Dimension; the tables that show it decide what a delete does. When you delete a table or a Page:

- A Variable or Dimension that another table still shows is kept.
- One that no other table shows is deleted with the table, after cfo.ai asks **Delete variable or dimension?**; **Keep with Ari** has Ari place it on another table instead. The dialog's text and buttons are listed in [Removing and deleting](/reference/table-blocks#removing-and-deleting).

To keep a Variable while you remove its table, first add it to another table, or move the table to another Page instead of deleting it.

## Write and format text on a Page

Click an empty line and type. An empty line reads **Type / for blocks**. The text saves as you type; nothing shows while a save works, and a line appears above the document only when a save fails. See [Page editor messages](/reference/interface#page-editor-messages).

Select some text to show the formatting toolbar: **Text style** (**Heading 1**, **Heading 2**, **Heading 3**, or **Normal**), **Bold**, **Italic**, **Underline**, **Strikethrough**, **Code**, **Link**, and **Bullet list**. **Link** asks for a web address, `http` or `https`; select it on linked text to remove the link.

You can also type a mark at the start of a line, then a space:

| Type | To get |
| --- | --- |
| `#`, `##`, or `###` | **Heading 1**, **Heading 2**, or **Heading 3** |
| `-` | A bullet list |
| `1.` | A numbered list |
| `[]` | A check list |
| `>` | A toggle, which hides the lines nested under it; on a heading, a toggle heading |
| `\|` | A quote |

**Tab** nests a list item under the one above it, and **Shift Tab** moves it back out.

Type **@** to insert a reference: a Page in this workspace, which appears as a chip that opens the Page; **Date**, which opens a calendar; or **Variable**, which inserts the Variable's current value and lets you narrow it to one Dimension item, such as Revenue where Region is West. Type **:** to pick an emoji.

A Text block written before the Page became a document opens as the same text, editable in place. A link to a Page in this workspace opens that Page in the app. **⌘**-click, **Ctrl**-click, or **Shift**-click opens a link in a new tab.
