You can attach files to a message in Ari chat, the same way you'd attach a file in a conversation with a coworker — useful when you want Ari to work from a screenshot of a P&L, an Excel export, or a PDF report that isn't already synced into your Model.

This is separate from the [CSV / Raw File Upload integration](/integrations/integrations-directory): that one brings a file's data into your Model as Actuals. Attaching a file in chat just lets Ari read it for the conversation you're having right now.

## What you can attach

| File type | Extensions | Max size |
| --- | --- | --- |
| Image | .png, .jpg, .webp | 10 MB |
| PDF | .pdf | 10 MB |
| Spreadsheet | .xlsx, .xls, .csv | 10 MB |

Up to **4 files per message**. Use the attach button in the chat input, select your file(s), and send — a thumbnail with the filename and file type shows above the input before you send, and stays attached to your message afterward.

## How Ari reads each type

- **Images** are passed to Ari directly, so it can read a screenshot the same way it would read a photo — including a table or chart baked into the image.
- **PDFs** have their text pulled out and included alongside your message. Ari reasons over that extracted text, so a scanned image with no underlying text layer won't read as well as a native PDF export.
- **Spreadsheets** (.xlsx, .xls, .csv) are parsed into structured data before Ari sees them. For a very large workbook, Ari may only see the first portion of it with a note that it was trimmed — if a big file seems to be getting cut off, ask Ari to focus on a specific sheet or range instead of the whole thing.

## Good to know

- Attachments are scoped to the message and conversation you send them in — there's no separate file library to browse later, so re-attach a file if you need Ari to reference it in a new conversation.
- A password-protected PDF or a corrupted file won't extract cleanly; Ari will tell you if it couldn't read an attachment rather than guessing at its contents.
