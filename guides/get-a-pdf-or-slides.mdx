To get a PDF report or a slide deck, such as a board deck, ask Ari. Ari makes the file from your Model's numbers and gives it to you as a download in the chat. cfo.ai has no button that saves a Page as a PDF, and printing a Page from your browser does not give a clean report. Asking Ari is the way to get a finished document.

## Ask Ari for a PDF report

Say what the report is for and what it should hold:

> Make a PDF board report for September: a one-paragraph summary, the P&L against plan, cash and cash runway, and headcount by department.

> Turn the Cash forecast Page into a two-page PDF I can send to our lender.

Ari reads the numbers from your Model and lays out the document in a private work area of its own. It gives you the finished file as a download card under its answer. When your workspace has a brand, the document uses the brand's colors, heading typeface, and logo; see [Brand your workspace](/guides/brand-your-workspace).

To change the report, say what to change, such as "Add the variance column" or "Make the summary shorter." Ari makes a new version of the file in the same chat.

Ari can also make a Word document (`.docx`) when you want to edit the text yourself.

## Ask Ari for a slide deck

Ask for the deck as a PowerPoint file (`.pptx`), or as a PDF with one slide per page:

> Make a 6-slide board deck as a PowerPoint file: revenue, gross margin, burn, cash runway, hiring, and the largest changes since last quarter.

Ari builds the deck in its private work area and gives it to you as a download card under its answer. Open a PowerPoint deck in PowerPoint, or a PDF in your PDF viewer, and check the slides before you present, especially when your brand uses an uploaded font, which the file does not embed.

## Print one Canvas block

A Canvas block can carry its own print button that prints that block alone, not the whole Page. Ask Ari to add one:

> Add a Print button to this chart.

The button opens your browser's print dialog, where you can print the block or save it as a PDF.

## When printing a Page from your browser looks wrong

cfo.ai has no print layout for a Page. Your browser prints the app as it is drawn on screen. A table draws only the rows and columns in view, so a long or wide table is cut off. For a clean copy, use one of these instead:

- Ask Ari for a PDF report, as above.
- Export the Page to Excel and print from Excel. See [Export a Page to Excel](/guides/download-a-spreadsheet).
- Send a read-only link, so readers see live numbers. See [Share a Page outside your workspace](/guides/share-a-page).

## Find the file later

The file stays in the chat where Ari made it. If you cannot find it, or a link Ari sent you no longer works, see [Find a file Ari made](/guides/find-things#find-a-file-ari-made).
