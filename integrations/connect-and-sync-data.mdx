Integrations bring financial and operating data into your cfo.ai Model. Connect a source when real accounting, people, customer, or spreadsheet history should inform your analysis.

## Choose the right source

Common starting points include:

- Accounting systems such as QuickBooks Online, Xero, or NetSuite.
- HR and payroll systems such as Rippling, Gusto, BambooHR, or Workday.
- CRM systems such as HubSpot or Salesforce.
- Google Sheets or a PostgreSQL-compatible database.
- A CSV or another supported file-upload flow for a source that is not connected directly.

Available sources and plan entitlements can vary. Ask Ari to check the catalog for the system you use.

A file used as a data source must be a CSV with a `.csv` extension, up to 50 MB. An Excel workbook is not accepted as a data source: attach it to a chat message for Ari to read, or ask Ari to [import it as a model](/getting-started/import-a-spreadsheet-model).

## Connect a business system

<Steps>
  <Step title="Tell Ari what you want to connect">
    Name the source and what you want to use it for.

    > Connect QuickBooks Online so we can build a monthly profit and loss statement.

  </Step>
  <Step title="Approve the connection">
    Ari opens or links you to the connection flow. Complete the sign-in and approval in your browser. Ari cannot enter your password or approve access for you.
  </Step>
  <Step title="Choose the tables to sync, when asked">
    Some sources, such as Shopify or your own database, show a table picker after you sign in. It reads **Choose which tables to sync**; only the tables you tick are imported, you can select up to 100 per connection, and the selection cannot be changed later, so include every table you expect to need. When cfo.ai knows the source well, the recommended tables are pre-selected. For Shopify that is the order, refund, fulfillment, customer, product, gift card, and shop tables, while the slow `transaction` table stays off unless you tick it. Select **Sync N tables** to start the import.
  </Step>
  <Step title="Wait for the initial load">
    cfo.ai starts loading the connected data after the source links. The import can continue in the background while you work on something else.

    An HR or payroll system such as Gusto may still be running its own first sync when cfo.ai's load begins. cfo.ai then waits and retries automatically about ten minutes later, up to twice, and Ari can tell you that it is waiting on the provider.
  </Step>
  <Step title="Check what arrived">
    Ask Ari whether the connection has finished, when data was last loaded, and which information is ready for analysis.

    > Check whether QuickBooks finished syncing and tell me which accounting periods are available.

    If a past period was wrong at the source and you have corrected it there, ask Ari to re-import the connection's full history. The routine refresh covers recent periods only.

  </Step>
</Steps>

## Connect from the sidebar instead

You can also start without Ari. Select **Connections** in the sidebar, then **Add**. The connection manager opens with three tabs:

- **Integrations** lists the business systems cfo.ai can import from, with a **Connect** button on each card and an **Upload** button for CSV files.
- **MCP** lists MCP servers Ari can call, such as Linear or Notion, plus **Add server** for one that is not listed.
- **API** lists other services' APIs Ari can reach, such as Stripe, plus **Add API**.

The same popover shows each connection's status and its actions. See [Connect data by hand](/getting-started/build-by-hand#connect-data) for the click paths.

A connection you start here still reports to you in chat. While your workspace is new, before any connection has completed a first sync, cfo.ai ties the new connection to your most recent chat, so Ari announces there when the link completes and when the first sync finishes or fails. After that, the result of a background sync, such as data that is ready to model or a first sync that failed, is still delivered to the chat you used most recently.

## Finish a connection you started earlier

If the source's sign-in window closes before you finish authorizing, for example because a pop-up was blocked or you are not the company's administrator, the connection card says **QuickBooks Online was not connected** (with the name of the source you chose) and explains that the window closed before authorization finished. Select **Try again** to reopen the sign-in on the same pending connection, or **Close**. Trying again does not create a second connection.

Connecting the same source again later continues the unfinished connection instead of starting a new one, whichever door you use: **Connect** on the source's card, **Resume** on the connection, a connect link, or asking Ari. This applies while no connection to that source is linked yet and the earlier one is still pending, partly linked, or failed because its link expired. A connection that lost access and reads **Reconnect required** is not picked up this way; use **Reconnect** on it. Continuing a connection someone else started needs edit access to that connection. When you continue a connection from a chat, that chat is the one Ari reports to when the link completes and the first sync finishes.

## Upload a file

If you attach a CSV in Ari chat, choose whether it should become a data source or stay attached only to the conversation.

- **Use as a data source** when the file's rows should become available in the Model.
- **Use in chat only** when Ari should read or summarize the file without importing it.

An uploaded data source is identified by its filename until you rename it. If the same filename already backs a connection, cfo.ai asks for confirmation before replacing it. Each file can be up to 50 MB.

cfo.ai reads each column's type from its values. A column whose header is exactly `yyyyMMdd` is read as a date in that compact form, such as `20260131`, instead of as a number; some point-of-sale exports use this header.

A column named `Date` does not place the file's rows on the calendar by itself. Tell Ari which column dates the rows, such as an invoice date or a period column, and Ari saves it as the source's time column; `first` and `last` over the source's rows then order by that column.

If the file is an existing financial model rather than a source-data export, ask Ari to [import and rebuild the spreadsheet model](/getting-started/import-a-spreadsheet-model) instead of treating the workbook as an ordinary data connection.

## Understand sync status

A connected source is ready only after its background load completes. A linked account, started import, or uploaded file does not by itself mean the resulting data is already available.

After the first load, connected integrations refresh once a night, automatically; there is no manual refresh button, so ask Ari to refresh a connection if you need newer data sooner. File uploads never refresh on their own. See [how integrations stay current](/integrations/integrations-directory#how-integrations-stay-current).

If the Model contains fewer rows than the source file, ask Ari which source records were included. A saved query may intentionally filter the source to match your request.

## Reconnect a source that lost access

When an accounting system such as QuickBooks Online or Xero revokes cfo.ai's access, for example after a password change or an expired authorization, the connection's status changes to **Reconnect required** after the next nightly refresh fails, and the connection shows a **Reconnect** action. Select it and sign in again to the company or organization the connection already holds.

A connection that is healthy or still syncing does not offer **Reconnect**. Signing in again cannot help it, so cfo.ai offers the action only when the source revoked access or when a sync failed and the connection needs attention. A connection whose setup never finished offers **Resume** instead.

If the provider's screen says you are already connected, its main button may read **Finish**; choose **Relink integration** there instead. **Finish** keeps the current authorization, and cfo.ai reports that the source **was not reconnected**, names the organization to sign in to, and offers **Try again**. For Xero, if the consent screen lists your organization as already connected, disconnect the cfo.ai app under **Connected apps** in Xero, then try again; the card names the app as Xero lists it.

## When a sync fails

A source that syncs through Fivetran, such as NetSuite, HubSpot, Salesforce, Google Sheets, or a database, stays connected when a sync fails on the provider's side. The connection shows that it needs attention and still offers **Reconnect**, which re-runs the provider's setup checks, but its status changes to **Reconnect required** only when the provider asks for a new authorization. cfo.ai retries the sync on the next nightly run, and you can ask Ari to retry it now.

## Connections for external tools

An integration imports business data into cfo.ai. A connected external MCP server or API gives Ari access to another service's tools. The cfo.ai MCP server does the opposite: it lets an outside AI client use cfo.ai's tools.

These are separate connection types with different setup and access controls.
