Use a Page's **Share** control when you want someone else to view a report, dashboard, or analysis. Share links are read-only and can open without requiring the recipient to sign in.

## Create a Page share link

<Steps>
  <Step title="Open the Page">
    Navigate to the Page you want to share and confirm that you have permission
    to manage its access.
  </Step>
  <Step title="Choose Share">
    Open the Page's **Share** control. The sharing panel identifies the Page so
    you can confirm you are sharing the intended report.
  </Step>
  <Step title="Choose the Scenario">
    When a Scenario selector is available, choose the Scenario the link should
    show. This matters when the same Page presents different results in Main and
    in an alternative Scenario.
  </Step>
  <Step title="Add password protection if needed">
    Turn on **Require password** when the recipient should enter a password
    before viewing the Page. Copy and share that password separately from the
    link.
  </Step>
  <Step title="Copy the link">
    Copy the generated link and send it to the intended recipient.
  </Step>
</Steps>

## Know what a link allows

A Page share link grants viewing access. It does not give the recipient permission to edit the Model or become a workspace administrator.

Use workspace access when someone needs to collaborate directly. Ari can help inspect the current team and can invite or remove workspace administrators when the acting user has the required access.

## Manage existing links

The sharing panel lists active links. Remove a link when the recipient should no longer be able to use it, and create a new link if the required Scenario or password changes.

Ari can explain where the **Share** control is, but you create and manage the link yourself from the Page.
