The cfo.ai MCP server, at `https://api.cfo.ai/mcp`, gives an AI agent Ari's public product tools. With them an agent can read a company's financial Model and, when the user asks, change it: Pages, Table blocks, Canvas blocks, formulas, Variables, Dimensions, Dimension mappings, and Scenarios, along with the workspace's connections, Skills, Triggers, memory, team and access, workspace settings, and the changelog's undo and redo. [MCP tools and call shapes](/agents/mcp-tools) lists every tool. These pages describe those tools for the agent and for the developer who connects it.

## One Model for the user, Ari, and the agent

The agent works in the user's live workspace, signed in as that user. There is no separate copy of the Model for agents. Whatever the agent builds appears in the workspace right away, where the user can inspect the assumptions, change the result, or continue the work with Ari. Every change to the Model, such as a formula, a Table block, or a Page edit, is recorded in the Model's changelog under the user's name and can be undone. Actions outside the Model are not in that changelog, and undo cannot reverse them: changes to connections, Skills, Triggers, memory, and access, such as invitations and share links, and emails sent. See [Work safely](/agent-instructions#work-safely).

## How to start

1. Connect the client and verify access with the [Agent instructions](/agent-instructions). A person setting up their own tool can follow [Connect an AI tool](/guides/connect-an-ai-client) instead.
2. Read the skills the server's instructions name, through `inspect_skills`: `build-model` before you create or change model logic, Variables, Dimensions, or saved tables; `build-visualizations` before you add a Canvas block; and `import-model` before you rebuild a Model from a workbook or export.
3. Inspect the existing workspace before you create anything, and reuse its Variables, Dimensions, and Pages.
