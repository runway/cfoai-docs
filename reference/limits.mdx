This page lists every size, count, and time limit in cfo.ai, grouped by part of the product. Each section ends with links to the pages that explain its limits. For what each plan includes, such as integration slots and AI usage, see [Plans and billing](/reference/plans-and-billing).

## Chat with Ari

| Limit | Value |
| --- | --- |
| Files attached to one message | 50. A larger selection attaches the first 50 in the order you picked them, and the notice names up to three of the rest. |
| Size of one image file | 10 MB |
| Size of one other file, such as a PDF, Excel workbook, ZIP, CSV, or text file | 500 MB |
| Quoted excerpts in one message | 5, each up to 2,000 characters |
| Size of a picture shown to Ari | 3.75 million pixels. A larger image is scaled down before Ari sees it, and Ari can reopen a part of an image enlarged up to 4 times, within the same ceiling, to read small text. An image of more than 25 million pixels cannot be opened as a picture at all, whole or in part. |
| Images and PDFs Ari looks at directly in one turn | 21 MB in all. Ari opens every attached file in its private workspace; an image or PDF it opens is also shown to it as a picture until the turn's 21 MB is used, and after that it reads the file in the workspace. When one request would carry more than 20 images and PDFs, an image wider or taller than 2,000 pixels is not shown; Ari reads it in the workspace instead. |
| Size of a CSV attached in a chat that can become a data source | 500 MB, the same as any other file; every CSV you can attach can become a data source |
| Recipients of one email Ari drafts | 10. On an email with Cc, the To and Cc addresses together count toward the 10, each address once |
| Size of a page of conventions you ask Ari to remember | 32 KiB of text, saved as up to 12 separate facts at a time |
| Files Ari delivers at once | 10, each up to 50 MB, and 250 MB in all |
| Time a download link for a file in a chat works | 5 minutes after you select the file; select it again for a new link |
| Table Ari posts in Slack as a Slack table | The first table in a message, up to 100 rows, 20 columns, and 10,000 characters of cell text; a larger or later table, and a table inside a code block, posts as text, and a message whose text around the table is too long for Slack posts whole as text |
| Image Ari posts in Slack, with a message or alone in a Slack conversation with Ari | 1 for each message or post, a PNG or JPEG saved in a chat, up to 10 MB; when an image sent with a message does not go through, the message is not sent, and when an image sent alone does not go through, Ari's reply still posts. Text sent in one message with the image, as a heading above it, holds up to 3,000 characters. See [Ari in Slack](/reference/chat#ari-in-slack) |
| Workspace memories Ari reads when it decides whether to reply to a Slack channel message | Up to 12, the closest matches to how Ari takes part in Slack, each up to 600 characters, and 6,000 bytes of text in all; a longer memory is cut at 600 characters. Private memories are not read for this decision. Once Ari has started on the message, it can read the private memories of the administrator whose access the channel uses. When saved memory does not answer within 5 seconds, Ari decides from the messages alone. See [Tell Ari when to reply in a channel](/guides/use-ari-in-slack#tell-ari-when-to-reply-in-a-channel) |
| Time Ari can spend writing one action before the action is cancelled | 3 minutes, counted from when Ari starts writing it; Ari then continues the reply, and a second action cancelled this way in the same reply ends the reply. See [When Ari takes too long to write one action](/reference/chat#when-ari-takes-too-long-to-write-one-action) |
| Length of one chat | No fixed limit; when a chat grows too large for Ari to read in one request, the chat says so, and you start a new chat |

See [Attach files to a chat](/guides/attach-files) and [Chat controls and messages](/reference/chat).

## Connections, syncs, and uploads

| Limit | Value |
| --- | --- |
| Size of a CSV uploaded as a data source | 500 MB, in a `.csv` file, with up to 16 MiB in one row |
| Size of a connected Google Sheet | 50 MB, read as an Excel workbook |
| Size of an Excel or CSV file read from Google Drive | 500 MB, the same as a file attached to a chat; a CSV becomes a data source only up to 50 MB |
| Tables one connection syncs | 100, for sources with a table picker |
| Time a connect link works, for someone else to connect a source | 7 days, or until someone finishes it or it is turned off |
| Sources in one connect link | 10 |
| Time cfo.ai waits for a provider's own first sync, or for a later sync the provider is still running after 45 minutes | 20 hours, checking every 10 minutes; the data from the last sync cfo.ai loaded stays as it is meanwhile |
| Time to plan a saved query | 40 seconds |
| History in the first load of QuickBooks Online or Xero | From January 1 of the previous year; the 3 most recent complete months arrive first |
| Months the nightly refresh of QuickBooks Online reads again | The last 3, plus the older months of a fiscal year whose net income no longer matches the balance sheet; ask Ari for a full-history import to correct other months |
| History in a full-history import of QuickBooks Online or Xero | Back to 2015 at the earliest |
| Rillet connections in one workspace | 1 |
| Start of the nightly refresh of connected sources | 02:00 UTC; each workspace's connections start at the workspace's own fixed point within the following hour |
| File Ari downloads from a connected API | 50 MiB, saved to the chat as an attachment; a JSON or text answer is read up to 1 MiB, and a response over its limit saves no partial file |
| OpenAPI 3 or Swagger 2.0 definition for an API connection | An address that answers within 20 seconds, fetched over `https` (an `http` address is tried at its `https` address), with a document of 12 MiB or less; a definition pasted with **Paste JSON** in Settings takes the same 12 MiB, and one Ari supplies inline, in a chat or as `spec_json` over MCP, is limited to 64 KiB |
| Time one load of a saved query's result can run | 15 minutes on its first attempt, 30 on its second, and 60 on its third and last; a load that reaches its limit is tried again, and its failure names the limit and the attempt |
| Times an import stopped for low worker memory runs again | 3. Imports and spreadsheet exports share a worker, and the worker stops its imports when less than 10% of its memory is free. A stopped import waits about 1 minute, then about 2 minutes, then about 30 minutes, each up to 20% shorter or longer, and runs again; a fourth stop fails it. A stop for low memory does not use up one of the import's other attempts, such as the three attempts of a saved query's load |
| When the nightly refresh runs a connection's saved queries | When every one of the workspace's sources has finished syncing, or at the four-hour cutoff for the sources that have; a source still syncing at the cutoff gets its queries within about two minutes after its sync ends, checked for up to 20 hours |
| Time one run of a sync setup for an MCP server or API can take | 10 minutes |
| Results one run of a sync setup can save | 10,000 pages for every sync, each page one source response of up to 1 MiB from an API or 2 MiB from an MCP server. A replace or snapshot sync without a changes-since filter saves page by page; an upsert, append, or changes-since sync holds its whole result, up to 16 MiB in all. A run stops after 10 minutes |
| Size of one page an MCP server returns to a sync setup | 2 MiB |
| One tool call in a sync page from an MCP server | 45 seconds; connecting, listing the server's tools, and the call each get 45 seconds. A time limit named in the tool's own description is the server's own; cfo.ai's limit applies either way |
| How often cfo.ai fetches a source that has no integration | Once a day, when the nightly run starts at 02:00 UTC or at the connection's own time of day; ask Ari to fetch again for newer data sooner |
| Fetches of one source that has no integration at a time | 1; a fetch asked for while another runs does not start |
| Time to enter a sign-in code that such a source sent you | 15 minutes from when the fetch asked for it; a code is 4 to 12 letters and digits |
| Public API addresses in one source Ari builds from public data | 8 |
| Size of one file a fetch delivers | 50 MiB |
| Redirects a fetch follows to a host outside the source's own domain | 3, each as a plain download that carries no login, key, or cookie |

See [How imported data loads](/reference/imported-data) and [Integrations directory](/reference/integrations).

## Tables, Pages, sharing, and exports

| Limit | Value |
| --- | --- |
| Items on one table axis before Ari notes that the table may be slow | About 1,000 |
| Scenarios one Canvas block can read | 3, counting only the Scenarios its datasets read; several datasets on one Scenario count once, and the Scenario you are viewing is not counted unless a dataset reads it, so a block that compares three named Scenarios opens from a fourth |
| Size of a Canvas block's source | 256 KB (262,144 bytes), pictures embedded in the block included |
| External links on one Page | 100 |
| Pages one share link opens | 50 |
| Length of a share link's memorable address | 3 to 64 characters: lowercase letters, digits, and single hyphens |
| Pages in one workbook Ari exports | 64 |
| Spreadsheet exports a workspace prepares at once | 1; [Export a Page to Excel](/guides/download-a-spreadsheet) says how Ari frees the slot |
| Time one spreadsheet export can run | 90 minutes from when a worker starts it; time waiting in the queue does not count. Calculation stops before the limit to leave time for writing the workbook: 10 minutes, or 2 minutes for each Page plus 1 minute, whichever is more, up to half the time left when calculation begins. The workbook holds every selected Page whose tables finished by then; see [Export a Page to Excel](/guides/download-a-spreadsheet#when-an-export-runs-out-of-time) |
| Time a spreadsheet export keeps running while its worker is low on memory | About 60 seconds: the export stops after twelve checks in a row, 5 seconds apart, that find less than 10% of the worker's memory free. The worker also runs imports and other exports, so another job may be the one using the memory. An export stopped alone fails and is not run again by itself. When one check stops two or more exports, each runs once more by itself, about 5 seconds later; an export runs at most twice, so a second stop fails it. [The cfo.ai interface](/reference/interface#download-spreadsheet) has its message |
| Time the **Download spreadsheet** button lists your past exports of a Page | 24 hours after you asked for each one, up to 10 of them, for this Page and Scenario; an export still queued or running is always listed |
| Time Ari can find your own newest export of a Page selection in a Scenario without starting one | While it is queued or running, and for 1 hour after it ends; an export of the same Pages in another Scenario is not found |
| Size of one calculated table an export reads | 64 MiB for one read, and 256 MiB for all of an export's reads together. An input, which is a table the export calculates only so that formulas can refer to it, is left out when it exceeds either limit or when the calculation engine stops it at its own time or memory limit, and the cells that read it keep their calculated values; a Page's own table that exceeds either limit fails the export. When the tables and their inputs together pass the workbook size limit, the workbook is written once more without the **Model inputs** sheet |
| Time one table calculation can run | 180 seconds; a calculation that reaches it is stopped, and retrying runs into the same limit. An export whose table reaches it while its formulas are worked out writes that table as values instead of failing; see [Export a Page to Excel](/guides/download-a-spreadsheet#when-an-export-runs-out-of-time). A calculation that outlasts one browser request keeps running, and the table, Canvas block, or chart keeps its loading state until the result arrives |
| Time Ari waits for one calculation of its own | 239 seconds, for a table, Page, Canvas, mapping, or validation read, so a 180-second calculation reaches Ari in the same call; Ari's other tools wait 60 seconds |
| Length of a formula in an exported workbook | 8,192 characters, Excel's limit; a longer formula is exported as its value |
| Size of one exported worksheet | Excel's 1,048,576 rows and 16,384 columns. A saved table that needs more is refused before anything is calculated, and a sheet may hold more than a million data cells when it fits |
| Size of an exported workbook | 256 MiB of sheet content before compression, and 128 MiB as the `.xlsx` file; the supporting formula rows and the **Export notes** sheet each have their own allowance of 1,000,000 cells |
| Cells one export calculates | 6,000,000 across the workbook, in up to 1,024 calculation requests. When the allowance runs out, the workbook keeps the Pages that finished, as it does when time runs out: the Page whose tables were still calculating is left out, and so are the Pages after it. An input the export did not reach is left out, and the cells that read it keep their calculated values. An export whose first Page with a table did not finish fails |
| Blocks whose view settings one browser remembers, such as a table's height, open panes, and expanded rows | 200 per browser, across workspaces; past that, the block whose settings were saved longest ago forgets them first |

See [Export a Page to Excel](/guides/download-a-spreadsheet), [Share a Page outside your workspace](/guides/share-a-page), and [Table block controls and messages](/reference/table-blocks).
