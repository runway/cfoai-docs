Use a share link when someone outside your workspace needs to read a report, such as a board update or a cash forecast. The link opens the Page read-only, without a sign-in or a cfo.ai account, in the Scenarios you choose. One link can open different Pages in several Scenarios, such as the Board summary in Main and the Revenue model in a Downside Scenario. Everyone inside your workspace can already open every Page, so you do not need a link for teammates.

<Tabs>
  <Tab title="Ask Ari">
    Ask Ari for a view-only link and name the Page:

    > Create a view-only link to the Board summary Page.

    Ari returns the link's address. To have one link open several Pages, name them all. The Page you name first is where the link lands, and every Page opens in the Scenario you name, or in your chat's Scenario when you name none:

    > Create a view-only link to the Board summary Page that also opens the Cash forecast and Headcount plan Pages.

    To have one link open Pages in several Scenarios, say which Scenario each Page belongs to:

    > Create a view-only link to the Board summary Page in Main that also opens the Revenue model Page in the Downside Scenario.

    Creating a link does not change the Model. Ari cannot add a password, give the link a memorable address, or turn a link off; do those in the **Share** panel.

      </Step>
      <Step title="Add more Pages, if you want them">
        Tick each other Page the link should open, or **Select all**. **Find a page** narrows a long list.

To tick a Page in every Scenario that has it, select **All scenarios**. A Scenario with no Page ticked is left out of the link. One link opens up to 50 Pages, and a Page counts once for each Scenario it opens in.

      </Step>

      </Step>

The link works for anyone who has it until you turn it off, and cfo.ai does not list it publicly. It never lets an outside reader edit anything; a teammate who opens it keeps the access they already have. To see exactly what a reader can and cannot see, read [Sharing and access](/concepts/sharing-and-access).

## Change a link's Scenario or password

1. Open the Page and select **Share**.
2. On the link, open **Link settings**.
3. Change **Shared scenario**, turn **Require password** on or off, or select **Generate password** for a new one. **Show password** displays the current password. You can change **Shared scenario** only on a link whose Pages are all in one Scenario. A link that opens Pages in several Scenarios does not show it, and an old link that opens a Page in every Scenario shows it as **All scenarios**, with nothing to pick.
4. Select **Save changes**.

Saving replaces the link: the old address stops working, people who opened the Page through it lose that access, and the new address is shown in its place. Send the new address to everyone who should keep reading.

To see what a link opens, select **Details** on it.

## Change the Pages a link opens

You can add or remove a link's Pages and Scenarios without changing its address or password, so people who saved the link keep one address. **Edit pages** is not offered on an old link that opens a Page in every Scenario, or on a link whose first Page is in a Scenario that was deleted. For those, create a new link, then turn off the old one.

1. Open one of the link's Pages and select **Share**.
2. On the link, select **Details**, then **Edit pages**.
3. Tick or untick Pages, and add or remove Scenarios, as you did when you created the link. The Page the link opens first stays ticked.
4. Read the line under the list, such as **Saving adds 1 page and removes 1 page. Anyone with this link can then open what you add.**, and select **Save**.

A Page you remove stops opening at once for everyone who opened the link. A Page you add opens the next time a reader opens the link's address. You cannot change the Page a link opens first; create a new link for that, then turn off the old one.

## Give the link a memorable address and a preview

A link without a password gets a short public address and a preview card. The card is the picture, headline, and description that chat and social apps show when someone pastes the link. cfo.ai writes the first preview from the Page. The card names cfo.ai unless an administrator turns on **Show the brand on link previews** in **Settings → General → Brand**; see [Brand your workspace](/guides/brand-your-workspace#who-sees-the-brand).

1. On the link, select **Edit share preview**.
2. Edit the card's **Headline** and **Description**. For a different picture, select **Create new artwork** and choose one of the three options it makes.
3. Select **Publish changes**.
4. To give the link a readable address, type it under **Memorable address**, such as `board-update`, and select **Update**. **Copy link** copies the address.

A memorable address can be guessed, so use a password-free link only for Pages you are happy for anyone with the address to read. Changing the address retires the old one. A link that needs a password has no memorable address or preview to edit; its password prompt shows your brand when **Show the brand on link previews** is on.

## See every link your workspace has shared

The **Share** panel lists the links of one Page. To see what the whole workspace has shared, ask Ari:

> What have we shared outside the workspace?

Ari lists the share links that are on and give access, newest first, across every Scenario. For each link it can tell you the Page readers land on and the other Pages the link opens, with the Scenario of each; when the link was created and, when a name is recorded, who created it; whether it needs a password; and how many accounts still hold access they got through it. That number counts accounts, including readers who never signed in. It does not count visits or people. A Page that was deleted, or that you cannot read, is counted but not named.

Ari reads up to 100 links at a time, so in a workspace with more, ask it for the rest. Links that are turned off are left out. Ari does not show a link's address, and it cannot turn a link off or change what it opens. To copy the address or change the link, open one of its Pages and select **Share**.

## Turn a link off

1. Open the Page and select **Share**.
2. On the link, select **Turn off external link** (the trash icon).
3. **Also remove access already granted by this link** starts checked, so everyone who opened the Page through the link loses access too. To let them keep their access, clear it.
4. Select **Turn off link**.

Every label and message in the **Share** panel and its **New link** view, and what a reader sees when a link is off, needs a password, or opens several Scenarios, is listed in [The cfo.ai interface](/reference/interface#share-panel).
